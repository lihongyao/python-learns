# 协程介绍

## 含义

协程（Coroutine）是一种轻量级的并发执行单元。多个协程通常运行在同一个线程中，由程序在合适的时机主动暂停当前协程，再恢复另一个协程。

协程不需要创建新的进程或系统线程，切换开销较小，适合包含大量 I/O 等待的任务。协程是并发执行，不等于多个 CPU 核心上的并行执行；一个协程长时间执行普通计算或阻塞调用时，其他协程也会被阻塞。

## 与线程、进程的区别

| 类型 | 调度方式 | 内存关系 | 常见场景 |
| --- | --- | --- | --- |
| 进程 | 操作系统调度 | 进程之间默认不共享 | CPU 密集型任务、隔离运行 |
| 线程 | 操作系统调度 | 同一进程中的线程共享内存 | I/O 密集型任务 |
| 协程 | 程序或事件循环调度 | 通常运行在同一线程 | 高并发 I/O 任务 |

# 生成器实现简单协程

带有 `yield` 的函数称为生成器函数。调用生成器函数不会立即执行函数体，而是返回一个生成器对象；每次调用 `next()` 时，函数执行到下一个 `yield` 并暂停。

```python
def task(name):
    print(f"{name}：开始")
    yield
    print(f"{name}：继续")
    yield
    print(f"{name}：结束")
    yield


task_a = task("任务 A")
task_b = task("任务 B")

next(task_a)  # 任务 A：开始
next(task_b)  # 任务 B：开始
next(task_a)  # 任务 A：继续
next(task_b)  # 任务 B：继续
next(task_a)  # 任务 A：结束
next(task_b)  # 任务 B：结束
```

这个例子通过手动调用 `next()` 模拟了协程的暂停和恢复。生成器适合表示逐步产生数据的过程，现代异步程序通常使用 `async`、`await` 和事件循环。

## 应用场景

- 网络请求、文件读写等 I/O 等待较多的任务。
- 需要在一个线程中管理大量轻量级任务的场景。

如果任务主要进行 CPU 计算，协程不会自动利用多个 CPU 核心，应考虑多进程或其他并行方案。

# `greenlet`

`greenlet` 是一个第三方库，提供用户态的执行上下文。它通过 `switch()` 让开发者手动在不同的 greenlet 之间切换。

安装：

```shell
pip install greenlet
```

示例：

```python
from greenlet import greenlet


def sing():
    print("在唱歌")
    g2.switch()
    print("唱完了")


def dance():
    print("在跳舞")
    g1.switch()
    print("跳完了")


if __name__ == "__main__":
    g1 = greenlet(sing)
    g2 = greenlet(dance)
    g1.switch()
```

输出顺序为：`在唱歌`、`在跳舞`、`唱完了`、`跳完了`。切换完全由代码控制；如果某个 greenlet 执行阻塞的 I/O，程序不会自动切换到其他 greenlet。

# `gevent`

## 含义

`gevent` 基于 `greenlet`，通过事件循环和协作式调度简化了任务切换。使用 `gevent` 提供的协作式 API（如 `gevent.sleep()`）时，当前 greenlet 会主动让出执行权。

安装：

```shell
pip install gevent
```

## 常用方法

- `gevent.spawn(func, *args)`：创建并启动一个 greenlet。
- `gevent.sleep(seconds=0)`：暂停当前 greenlet，并让其他任务运行。
- `Greenlet.join()`：等待一个任务完成。
- `gevent.joinall(greenlets)`：等待多个任务全部完成。

## 基本示例

```python
import gevent


def sing(name):
    for i in range(2):
        print(f"{name}在唱歌，第{i + 1}次")
        gevent.sleep(0.1)


if __name__ == "__main__":
    tasks = [
        gevent.spawn(sing, "张三"),
        gevent.spawn(sing, "李四"),
    ]
    gevent.joinall(tasks)
```

`gevent.sleep()` 是可识别的让出执行操作，两个任务会交替运行。普通的 `time.sleep()` 会阻塞当前线程，默认不会让其他 greenlet 运行。

## `monkey.patch_all()`

如果现有代码大量使用标准库中的阻塞函数，可以使用 `gevent` 的 monkey patch 将部分函数替换为协作式版本。补丁应尽早执行，通常放在导入需要被替换的模块之前：

```python
from gevent import monkey


monkey.patch_all()

import gevent
import time


def task(name):
    for i in range(2):
        time.sleep(0.1)  # 已被替换为协作式 sleep
        print(f"{name}：第{i + 1}次")


if __name__ == "__main__":
    gevent.joinall([
        gevent.spawn(task, "任务 A"),
        gevent.spawn(task, "任务 B"),
    ])
```

`monkey.patch_all()` 会修改部分模块的行为，可能影响第三方库，使用前应确认项目兼容性。无法被 gevent 识别的阻塞调用仍然会阻塞整个线程。

# `asyncio`

现代 Python 异步编程通常优先使用标准库 `asyncio`。`async def` 定义协程函数，`await` 暂停当前协程并等待另一个可等待对象完成。

```python
import asyncio


async def task(name):
    print(f"{name}：开始")
    await asyncio.sleep(0.1)
    print(f"{name}：结束")


async def main():
    await asyncio.gather(
        task("任务 A"),
        task("任务 B"),
    )


if __name__ == "__main__":
    asyncio.run(main())
```

在 `async def` 中应使用支持异步的 API，例如 `await asyncio.sleep()`；直接调用 `time.sleep()` 等阻塞函数会阻塞事件循环，影响其他协程运行。

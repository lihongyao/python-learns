# 多任务

## 含义

多任务是指程序在同一时间段内处理多个任务。例如，唱歌和跳舞可以同时进行。

普通代码通常按顺序执行，一个任务完成后才会执行下一个任务：

```python
import time


def sing():
    print("我在唱歌")
    time.sleep(1)
    print("唱完了")


def dance():
    print("我在跳舞")
    time.sleep(1)
    print("跳完了")


sing()
dance()
```

上面的代码需要先完成 `sing()`，再执行 `dance()`。要让多个任务交替或同时推进，就需要使用多任务技术。

## 实现方式

Python 中常见的多任务实现方式有：

1. **线程**：进程中的执行单元，共享进程的内存，适合 I/O 密集型任务。
2. **进程**：操作系统进行资源分配的基本单位，进程之间相互独立。
3. **协程**：由程序主动切换的轻量级执行单元，适合高并发 I/O 场景。

一个进程至少包含一个线程，该线程通常称为主线程；一个进程可以创建多个子线程。线程不能脱离进程单独存在。

在 CPython 中，CPU 密集型任务通常不能仅靠多线程充分利用多个 CPU 核心，可以考虑使用多进程。

# 多线程

## 创建线程

使用 `threading` 模块中的 `Thread` 类创建线程：

```python
import threading
```

常用参数：

| 参数 | 含义 |
| --- | --- |
| `target` | 线程启动后要执行的函数。传入函数名，不要写成函数调用。 |
| `args` | 以元组形式传递位置参数。 |
| `kwargs` | 以字典形式传递关键字参数。 |
| `name` | 设置线程名称，便于调试和日志记录。 |

线程常用方法：

- `start()`：启动线程，之后由线程执行 `target` 指定的函数。
- `join(timeout=None)`：等待线程结束。调用线程会在此处阻塞。

## 执行没有参数的任务

```python
import threading
import time


def sing():
    print("我在唱歌")
    time.sleep(0.1)
    print("唱完了")


def dance():
    print("我在跳舞")
    time.sleep(0.1)
    print("跳完了")


if __name__ == "__main__":
    t1 = threading.Thread(target=sing, name="sing-thread")
    t2 = threading.Thread(target=dance, name="dance-thread")

    t1.start()
    t2.start()

    t1.join()
    t2.join()
    print("所有任务完成")
```

创建线程时使用 `target=sing`，表示把 `sing` 函数交给线程；使用 `target=sing()` 则会在创建线程前直接调用函数。

## 执行带参数的任务

### 使用 `args`

`args` 使用元组传递位置参数。即使只有一个参数，也要保留结尾的逗号：

```python
import threading
import time


def greet(name, count):
    for _ in range(count):
        print(f"{name}在线程中执行")
        time.sleep(0.1)


if __name__ == "__main__":
    thread = threading.Thread(target=greet, args=("张三", 2))
    thread.start()
    thread.join()
```

### 使用 `kwargs`

`kwargs` 使用字典传递关键字参数，字典的键必须与函数参数名一致：

```python
import threading


def greet(name, message):
    print(f"{name}：{message}")


if __name__ == "__main__":
    thread = threading.Thread(
        target=greet,
        kwargs={"name": "李四", "message": "你好"},
    )
    thread.start()
    thread.join()
```

## 线程调度顺序

多个线程的执行顺序由操作系统调度决定，不能依赖某个固定顺序。下面的输出顺序可能每次不同：

```python
import threading
import time


def task():
    time.sleep(0.1)
    current = threading.current_thread()
    print(f"当前线程是：{current.name}")


if __name__ == "__main__":
    threads = [
        threading.Thread(target=task, name=f"Thread-{i}")
        for i in range(5)
    ]

    for thread in threads:
        thread.start()
    for thread in threads:
        thread.join()
```

`sleep()` 只能模拟任务耗时，不能用来保证线程执行顺序。需要等待某个线程完成时，应使用 `join()` 或其他同步工具。

# 共享数据与资源竞争

## 共享数据

同一进程中的线程共享进程内的全局变量、堆对象等数据：

```python
from threading import Thread


data = []


def write_data():
    data.extend([1, 2, 3])


def read_data():
    print(data)


if __name__ == "__main__":
    writer = Thread(target=write_data)
    reader = Thread(target=read_data)

    writer.start()
    writer.join()  # 确保写入完成后再读取
    reader.start()
    reader.join()
```

共享数据便于线程之间交换信息，但多个线程同时修改同一数据时需要额外的同步保护。

## 资源竞争

多个线程同时访问或修改同一资源时，可能发生资源竞争。例如，两个线程同时对一个共享计数器执行“读取、加一、写回”操作，中间步骤可能互相覆盖。

```python
from threading import Thread


counter = 0


def increment():
    global counter
    for _ in range(100_000):
        counter += 1


if __name__ == "__main__":
    t1 = Thread(target=increment)
    t2 = Thread(target=increment)
    t1.start()
    t2.start()
    t1.join()
    t2.join()

    print(counter)
```

这里的最终结果不应被写死。共享数据的操作是否安全与 Python 实现、版本和线程调度有关，不能因为一次运行得到预期结果就认为代码一定没有竞争问题。

# 线程同步

线程同步用于协调多个线程的执行顺序或访问共享资源，避免数据不一致。常用方式包括线程等待和互斥锁。

## 线程等待 `join()`

`join()` 只负责等待线程结束，不负责保护共享数据：

```python
from threading import Thread


result = []


def prepare_data():
    result.extend(["数据已准备"])


if __name__ == "__main__":
    thread = Thread(target=prepare_data)
    thread.start()
    thread.join()
    print(result)  # ['数据已准备']
```

如果主线程必须等待子线程执行完毕后再继续，就调用该子线程的 `join()`。

## 互斥锁 `Lock`

互斥锁保证同一时刻只有一个线程进入临界区（访问共享数据的代码区域）。

```python
from threading import Lock, Thread


counter = 0
lock = Lock()


def increment():
    global counter
    for _ in range(100_000):
        with lock:
            counter += 1


if __name__ == "__main__":
    t1 = Thread(target=increment)
    t2 = Thread(target=increment)
    t1.start()
    t2.start()
    t1.join()
    t2.join()

    print(counter)  # 200000
```

`with lock:` 会自动获取并释放锁，即使临界区中发生异常也能避免锁一直占用。也可以手动调用：

```python
lock.acquire()
try:
    # 访问共享资源
    pass
finally:
    lock.release()
```

## 死锁

死锁是指两个或多个线程相互等待对方持有的锁，导致所有线程都无法继续执行。

常见预防方式：

- 尽量缩小锁的保护范围，并在完成共享数据操作后立即释放。
- 多把锁按固定顺序获取，避免不同线程以相反顺序加锁。
- 优先使用 `with lock`，确保锁能够释放。
- 必要时为 `acquire()` 设置超时时间，及时发现异常等待。

# 文件

## 含义

文件是存储在硬盘、U 盘等持久化设备上的一段数据，用于长期保存信息。

## 文件类型

计算机中的数据最终都以二进制形式存储。根据内容和用途，文件通常分为文本文件和二进制文件。

### 文本文件

文本文件主要保存人类可读的字符，例如 `.txt`、`.py` 和 `.md` 文件。字符会按照指定的编码（如 `UTF-8`）转换为二进制数据后保存。

### 二进制文件

二进制文件通常保存图片、视频、音频和可执行程序等数据，例如 `.jpg`、`.mp3` 和 `.exe` 文件。处理这类文件时，应使用二进制模式读写字节数据。

## 文件路径

路径用于定位文件或目录。

### 绝对路径

从根目录开始的完整路径，与当前工作目录无关：

- Windows：`C:\Users\张三\test.txt`
- Linux/macOS：`/home/zhangsan/test.txt`

### 相对路径

以当前工作目录为基准的路径：

- `./test.txt`：当前目录下的 `test.txt`，`./` 通常可以省略。
- `../test.txt`：上一级目录下的 `test.txt`。
- `data/test.txt`：当前目录的 `data` 子目录下的文件。

> 注意：相对路径依赖程序运行时的当前工作目录。项目内部引用文件时通常使用相对路径，并通过 `pathlib` 或 `os.path` 拼接路径。

# 基本操作

文件操作通常包括三个步骤：

1. 打开文件：使用 `open()` 获取文件对象。
2. 读取或写入：通过文件对象的方法处理数据。
3. 关闭文件：使用 `close()` 释放资源，或使用 `with` 自动关闭。

## 打开文件

语法格式：

```python
file = open(file_path, mode="r", encoding=None)
```

常用参数：

- `file`：文件路径。
- `mode`：访问模式，默认为只读文本模式 `"r"`。
- `encoding`：文本编码。建议在文本模式下明确指定，例如 `encoding="utf-8"`。

### 基础模式

| 模式 | 含义 |
| --- | --- |
| `r` | 只读，文件必须存在。 |
| `w` | 只写，覆盖原内容；文件不存在时创建。 |
| `a` | 只写追加，写入内容放在文件末尾；文件不存在时创建。 |
| `x` | 独占创建，文件已存在时抛出 `FileExistsError`。 |
| `t` | 文本模式，默认模式，通常省略。 |
| `b` | 二进制模式，需与其他模式组合，如 `rb`、`wb`。 |

### 读写组合模式

在基础模式后加 `+` 表示同时读写：

- `r+`：读写，文件必须存在，初始位置在开头。
- `w+`：读写，覆盖原内容；文件不存在时创建。
- `a+`：读写，写入时追加到文件末尾；文件不存在时创建。

例如，`rb` 表示二进制只读，`wb` 表示二进制覆盖写入，`r+b` 表示二进制读写。

> 注意：`w` 和 `w+` 会清空原文件内容，使用时应确认路径和模式正确。

## 文件对象

```python
file = open("test.txt", "r", encoding="utf-8")

print(file.name)     # test.txt
print(file.mode)     # r
print(file.encoding) # utf-8
print(file.closed)   # False

file.close()
print(file.closed)   # True
```

常用属性：

- `file.name`：文件路径。
- `file.mode`：文件打开模式。
- `file.encoding`：文本编码。
- `file.closed`：文件是否已关闭。

## 关闭文件

使用 `close()` 可以关闭文件对象：

```python
file = open("test.txt", "r", encoding="utf-8")
file.close()
```

更推荐使用 `with`，代码块结束后文件会自动关闭，即使代码块中发生异常也会执行关闭操作：

```python
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)

print(file.closed)  # True
```

文件关闭后不能继续读写：

```python
file.close()
# file.read()  # ValueError: I/O operation on closed file.
```

> 注意：文件写入通常先进入缓冲区。及时使用 `with` 或 `close()`，可以确保缓冲区内容被刷新并释放文件资源。

# 读取文件

假设当前目录下的 `test.txt` 内容如下：

```text
PythonStudy
张三
30
```

## `read(size=-1)`

读取文件内容并返回字符串。文本模式下，`size` 表示读取的字符数；二进制模式下，表示读取的字节数。省略 `size` 或传入负数时读取剩余的全部内容。

```python
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

读取指定数量的字符：

```python
with open("test.txt", "r", encoding="utf-8") as file:
    print(file.read(6))  # Python
```

`read()` 会把读取的内容一次性放入内存。处理大文件时，应优先使用逐行读取或分块读取。

## `readline()`

每次读取一行，返回的字符串通常保留行末的换行符。到达文件末尾时返回空字符串 `""`。

```python
with open("test.txt", "r", encoding="utf-8") as file:
    print(file.readline(), end="")
    print(file.readline(), end="")
    print(file.readline(), end="")
    print(file.readline() == "")  # True
```

循环读取所有行：

```python
with open("test.txt", "r", encoding="utf-8") as file:
    while True:
        line = file.readline()
        if line == "":
            break
        print(line, end="")
```

实际开发中，也可以直接遍历文件对象，代码更简洁且不会一次性加载全部内容：

```python
with open("test.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

## `readlines()`

读取所有行，返回一个列表，每个元素代表一行：

```python
with open("test.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()
    print(lines)  # ['PythonStudy\n', '张三\n', '30\n']

for line in lines:
    print(line.strip())
```

`readlines()` 会将所有行加载到内存，不适合直接处理非常大的文件。

## 分块读取

处理大文件时，可以每次读取固定大小的数据块：

```python
with open("large_file.log", "r", encoding="utf-8") as file:
    while True:
        chunk = file.read(1024)
        if not chunk:
            break
        print(chunk, end="")  # 在这里处理数据块
```

# 写入文件

## `write()`

`write()` 写入字符串，并返回实际写入的字符数。文件必须以可写模式打开：

```python
with open("output.txt", "w", encoding="utf-8") as file:
    count = file.write("第一行\n")
    file.write("第二行\n")
    print(count)
```

只读模式不能写入：

```python
with open("test.txt", "r", encoding="utf-8") as file:
    # file.write("内容")  # io.UnsupportedOperation: not writable
    pass
```

## `writelines()`

`writelines()` 接收一个字符串可迭代对象，并连续写入其中的内容。它不会自动添加换行符：

```python
with open("output.txt", "w", encoding="utf-8") as file:
    file.writelines(["第一行\n", "第二行\n"])
```

## 追加写入

使用 `a` 模式可以保留原内容，将新内容写入文件末尾：

```python
with open("output.txt", "a", encoding="utf-8") as file:
    file.write("追加的一行\n")
```

# 文件定位

文件对象内部维护一个当前位置，也称为文件指针。

- `tell()`：返回当前位置。
- `seek(offset, whence=0)`：移动当前位置。
  - `whence=0`：以文件开头为参考位置（默认）。
  - `whence=1`：以当前位置为参考位置。
  - `whence=2`：以文件末尾为参考位置。

在文本模式下，`seek()` 的偏移量通常应使用之前由 `tell()` 返回的位置；在二进制模式下偏移量按字节计算。

```python
with open("test.txt", "r", encoding="utf-8") as file:
    print(file.read(6))  # Python
    print(file.tell())

    file.seek(0)
    print(file.read(6))  # Python
```

# 目录和路径操作

## `os` 模块

### 文件和目录操作

- `os.rename(src, dst)`：重命名文件或目录。
- `os.remove(path)`：删除文件。
- `os.mkdir(path)`：创建单级目录。
- `os.makedirs(path, exist_ok=False)`：创建多级目录。
- `os.rmdir(path)`：删除空目录。
- `shutil.rmtree(path)`：递归删除目录树，使用时要谨慎。
- `os.getcwd()`：获取当前工作目录。
- `os.chdir(path)`：修改当前工作目录。

### 目录遍历与判断

- `os.listdir(path)`：获取目录下的名称列表。
- `os.scandir(path)`：遍历目录并获取目录项信息。
- `os.walk(top)`：递归遍历目录树。
- `os.path.exists(path)`：判断路径是否存在。
- `os.path.isfile(path)`：判断是否为文件。
- `os.path.isdir(path)`：判断是否为目录。

### 路径处理

- `os.path.join(path, *paths)`：拼接路径。
- `os.path.abspath(path)`：获取绝对路径。
- `os.path.basename(path)`：获取最后一级名称。
- `os.path.dirname(path)`：获取目录部分。
- `os.path.splitext(path)`：分离文件名和扩展名。
- `os.path.getsize(path)`：获取文件大小（字节）。

常用的复制和移动操作来自 `shutil` 模块：

- `shutil.copyfile(src, dst)`：复制文件内容。
- `shutil.copytree(src, dst)`：复制目录树。
- `shutil.move(src, dst)`：移动文件或目录。

## `pathlib` 模块

`pathlib` 使用面向对象的方式处理路径，跨平台代码更直观：

```python
from pathlib import Path


path = Path("data") / "test.txt"
print(path)  # data/test.txt
print(path.exists())
print(path.is_file())
print(path.name)  # test.txt
print(path.parent)  # data
```

常用方法：

- `Path.cwd()`：获取当前工作目录。
- `Path.mkdir(parents=True, exist_ok=True)`：创建目录。
- `Path.iterdir()`：遍历当前目录。
- `Path.glob(pattern)`：按模式查找当前目录中的路径。
- `Path.rglob(pattern)`：递归按模式查找路径。
- `Path.read_text()`、`Path.write_text()`：读写文本文件。

# 特殊文件处理

## 二进制文件

使用 `rb`、`wb` 或 `ab` 模式处理二进制文件。二进制模式返回或接收 `bytes`，不需要设置 `encoding`：

```python
with open("image.png", "rb") as file:
    data = file.read()
    print(type(data))  # <class 'bytes'>
```

## CSV 文件

使用 `csv` 模块读写 CSV 文件。读取或写入时通常指定 `newline=""`，避免换行符在不同平台上重复：

```python
import csv


with open("data.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

## JSON 文件

使用 `json` 模块在 Python 对象和 JSON 文本之间转换：

```python
import json


with open("data.json", "r", encoding="utf-8") as file:
    data = json.load(file)
    print(data)
```

写入 JSON：

```python
import json


data = {"name": "张三", "age": 18}
with open("data.json", "w", encoding="utf-8") as file:
    json.dump(data, file, ensure_ascii=False, indent=2)
```

# 案例：图片备份

复制图片等二进制文件时，读取和写入都要使用二进制模式：

```python
with open("logo.jpg", "rb") as source:
    content = source.read()

with open("logo_backup.jpg", "wb") as target:
    target.write(content)

print("备份完成")
```

对于较大的文件，可以分块复制，避免一次性占用过多内存：

```python
with open("logo.jpg", "rb") as source, open("logo_backup.jpg", "wb") as target:
    while True:
        chunk = source.read(1024 * 1024)
        if not chunk:
            break
        target.write(chunk)
```

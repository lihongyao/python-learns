#  文件

## 文件类型

文件最终都保存为字节；文本模式会额外进行编码、解码和换行转换。

| 模式 | 读写的数据类型 | 适用场景 |
| --- | --- | --- |
| 文本模式 `t` | `str` | 文本、CSV、JSON |
| 二进制模式 `b` | `bytes` 等字节数据 | 图片、音频、压缩包 |

文本文件建议显式指定 `encoding="utf-8"`；二进制模式不能传入 `encoding`。文件扩展名不会自动决定读写模式。

## 文件路径

- **绝对路径**：从根目录或盘符开始。
- **相对路径**：相对于当前工作目录，不一定是脚本所在目录。
- 使用 `pathlib.Path` 和 `/` 拼接路径，避免手动拼接分隔符。

普通脚本需要相对自身定位资源时，可以使用：

```python
from pathlib import Path

base_dir = Path(__file__).resolve().parent
path = base_dir / "data" / "notes.txt"
```

交互环境通常没有 `__file__`。`Path.cwd()` 获取当前工作目录；`Path("~/data").expanduser()` 才会展开用户目录。

# 基本操作

## 打开文件

常用形式为 `open(path, mode="r", encoding="utf-8")`，返回文件对象；父目录必须已经存在。

| 模式 | 文件不存在 | 文件已存在 |
| --- | --- | --- |
| `r` | 抛出 `FileNotFoundError` | 只读 |
| `w` | 创建 | 打开时立即清空，再写入 |
| `a` | 创建 | 保留内容，写入时追加到末尾 |
| `x` | 创建 | 抛出 `FileExistsError` |

- `t` 是默认文本模式，`rb`、`wb` 等表示二进制模式。
- `+` 表示同时读写，不表示追加：`r+` 保留内容，`w+` 清空内容，`a+` 的写入仍追加到末尾。
- `a+` 打开后要从头读取，应先 `seek(0)`。

## 关闭文件与 `with`

优先使用 `with`，离开代码块时自动关闭文件，包括块内抛出异常的情况：

```python
from pathlib import Path

Path("notes.txt").write_text("Python\n张三\n", encoding="utf-8")

with open("notes.txt", encoding="utf-8") as file:
    print(file.read(6))  # Python

print(file.closed)  # True
```

- `close()` 关闭文件，关闭后继续读写会抛出 `ValueError`。
- `with` 负责资源清理，不会自动吞掉读写异常。
- 常用属性有 `name`、`mode`、`encoding`（文本文件）和 `closed`。

# 读取文件

## 常用方式

以下示例继续使用前面的 `notes.txt`：

| 操作 | 返回结果 | 注意事项 |
| --- | --- | --- |
| `read(size=-1)` | 文本为 `str`，二进制为 `bytes` | 默认读取剩余全部内容 |
| `readline()` | 一行内容，通常包含换行符 | 到达末尾返回 `""` 或 `b""` |
| `readlines()` | 行列表 | 通常一次加载所有剩余行 |
| `for line in file` | 逐行迭代 | 适合文本大文件 |

文本模式的 `size` 按字符计算，二进制模式按字节计算。空行通常是 `"\n"`，与文件结束的 `""` 不同。

```python
with open("notes.txt", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
# Python
# 张三
```

`strip()` 会同时去掉两端的空格、制表符等；只需去掉换行时，不要误删有效空白。

## 分块读取

```python
with open("notes.txt", "rb") as file:
    while chunk := file.read(64 * 1024):
        # 在这里处理本次读取的字节块
        pass
```

分块读取控制内存占用，但数据块不一定与一行或一条业务记录对齐。

# 写入文件

## `write()` 和 `writelines()`

```python
with open("output.txt", "w", encoding="utf-8") as file:
    print(file.write("第一行\n"))  # 4
    file.writelines(["第二行\n", "第三行\n"])

with open("output.txt", "a", encoding="utf-8") as file:
    file.write("追加内容\n")
```

- 文本模式的 `write()` 接收字符串，返回写入的字符数；二进制模式写入字节数据，返回字节数。
- `write()`、`writelines()` 都不会自动添加换行；`writelines()` 返回 `None`。
- 文本模式默认会按平台处理换行；需要控制时使用 `newline` 参数。

## 缓冲与持久化

写入通常先进入缓冲区，`flush()` 或关闭文件会刷新 Python 层的缓冲。`flush()` 不等于数据已经持久化到物理设备；需要更强持久化保证时，再结合 `os.fsync()` 等机制。

# 文件定位

- `tell()`：返回当前位置。
- `seek(offset, whence=0)`：移动位置；`0`、`1`、`2` 分别表示相对开头、当前位置、末尾。
- 二进制模式按字节定位；文本模式的 `tell()` 返回可用于恢复位置的标记，不能当作字符下标做运算。
- 文本模式通常仅支持从开头定位到 `0` 或之前 `tell()` 的结果，以及 `seek(0, 1)`、`seek(0, 2)`。

```python
with open("notes.txt", encoding="utf-8") as file:
    file.read(6)
    position = file.tell()
    first = file.readline()
    file.seek(position)
    print(file.readline() == first)  # True
```

# 目录和路径操作

## `pathlib` 模块

```python
from pathlib import Path

path = Path("data") / "report.txt"
path.parent.mkdir(parents=True, exist_ok=True)
path.write_text("学习笔记", encoding="utf-8")

print(path.name)                           # report.txt
print(path.suffix)                         # .txt
print(path.read_text(encoding="utf-8"))     # 学习笔记
```

| 操作 | 用途 |
| --- | --- |
| `Path.cwd()`、`path.resolve()` | 当前工作目录、解析后的绝对路径 |
| `path.name`、`stem`、`suffix`、`parent` | 文件名、无后缀名称、末级后缀、父目录 |
| `exists()`、`is_file()`、`is_dir()` | 检查路径状态 |
| `iterdir()` | 遍历直接子项，顺序不保证 |
| `glob("*.txt")`、`rglob("*.txt")` | 按模式查找、递归查找 |
| `read_text()`、`write_text()` | 整体读写文本，写入会覆盖 |
| `read_bytes()`、`write_bytes()` | 整体读写字节 |
| `rename()`、`replace()` | 重命名、替换目标路径 |
| `unlink()`、`rmdir()` | 删除文件或符号链接、删除空目录 |

`mkdir()` 不会创建文件；`write_text()` 不会自动创建父目录。路径检查与实际操作之间状态可能改变，不能仅靠 `exists()` 代替异常处理。

## `os` 和 `shutil` 模块

- `os.getcwd()`、`os.chdir()`：获取、修改当前工作目录；修改会影响同一进程中其他代码的相对路径。
- `os.scandir()`、`os.walk()`：遍历目录项、递归遍历目录树。
- `os.path.join()`、`basename()`、`dirname()`、`splitext()`：传统路径处理接口。
- `shutil.copyfile()`：复制文件内容；`copy2()` 还尝试保留元数据。
- `shutil.copytree()`、`shutil.move()`：复制目录树、移动文件或目录。
- `shutil.rmtree()`：递归删除目录树；调用前确认目标路径。

# 特殊文件处理

## CSV 文件

用 `csv` 模块处理分隔符和引号，不要简单用 `split(",")` 解析 CSV。读写时指定 `newline=""`，由模块处理换行：

```python
import csv

with open("users.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["姓名", "年龄"])
    writer.writerow(["张三", 18])

with open("users.csv", encoding="utf-8", newline="") as file:
    rows = list(csv.DictReader(file))
    print(rows[0])  # {'姓名': '张三', '年龄': '18'}
```

CSV 读取结果默认是字符串，数值等类型需要自行转换。

## JSON 文件

```python
import json

with open("user.json", "w", encoding="utf-8") as file:
    json.dump({"name": "张三", "age": 18}, file, ensure_ascii=False, indent=2)

with open("user.json", encoding="utf-8") as file:
    data = json.load(file)
    print(data["name"])  # 张三
```

- `dump()`、`load()` 操作文件对象；`dumps()`、`loads()` 操作字符串。
- `ensure_ascii=False` 保留中文字符，文件编码仍由 `open()` 决定。
- 同一文件连续多次 `dump()` 不会自动形成一个合法 JSON 文档。
- `pickle` 可以序列化更多 Python 对象，但不能加载不可信来源的数据。

# 案例：图片备份

假设当前目录已有 `logo.jpg`，用二进制模式分块复制：

```python
with open("logo.jpg", "rb") as source, open("logo_backup.jpg", "wb") as target:
    while chunk := source.read(1024 * 1024):
        target.write(chunk)
```

普通文件复制也可以直接用 `shutil.copyfile()`，无需自己实现循环。

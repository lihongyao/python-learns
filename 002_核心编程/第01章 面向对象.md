# 面向对象

## 含义

面向对象是一种抽象化的编程思想。它把数据和操作数据的方法组织在对象中，适合构建结构复杂、规模较大的程序。

常见的编程思想有面向过程和面向对象，两者各有适用场景。

## 面向过程和面向对象

### 面向过程

面向过程关注“怎么做”，先分析完成任务的步骤，再把每个步骤编写成函数，最后按顺序调用这些函数。

### 面向对象

面向对象关注“谁来做”，先定义对象及其行为，再让对象协作完成任务。对象通常由属性和方法组成。

### 区别

以洗衣服为例：手洗需要按照装水、加洗衣粉、浸泡、搓洗、漂洗等步骤逐一操作，类似面向过程；使用洗衣机时，只需设置模式并启动，洗衣机负责完成具体步骤，类似面向对象。

**面向过程**：关注具体的执行步骤。

**面向对象**：关注参与任务的对象及其行为，将实现细节封装在对象内部。

## 三大特性

面向对象的三大特性是封装、继承和多态。

### 封装

将数据（属性）和操作数据的方法（行为）组织在类中，对外隐藏实现细节，只提供必要的操作方式。

### 继承

子类可以复用父类的属性和方法，并根据需要扩展或重写父类功能。

### 多态

同一种行为作用于不同类型的对象时，可以产生不同的结果。例如，不同动物都能“叫”，但叫声各不相同。

# 类与对象

## 类

类是对一组具有相同属性和行为的对象的抽象描述。

- 属性：对象的特征，例如姓名、年龄。
- 方法：对象能够执行的操作，例如学习、行走。

类是抽象的概念，可以把它理解为创建对象的模板。

## 对象

对象是类的具体实例。根据同一个类可以创建多个相互独立的对象。

Python 中“万物皆对象”，数据、函数、模块甚至类本身都是对象。

```python
import copy


def func():
    pass


print(type("Hello"))  # <class 'str'>
print(type(3.14))     # <class 'float'>
print(type(func))     # <class 'function'>
print(type(copy))     # <class 'module'>
```

> 注意：通常先定义类，再根据类创建对象。

## 定义类

语法格式：

```python
class 类名:
    """类的描述信息"""
    类体
```

类名应遵守标识符命名规则，通常使用大驼峰命名法，并且做到见名知意。

```python
class Person:
    """人类"""
    pass
```

`pass` 是占位语句，表示暂时不执行任何操作。

## 实例化对象

语法格式：

```python
对象名 = 类名()
```

```python
class Person:
    pass


p1 = Person()
p2 = Person()

print(type(p1))  # <class '__main__.Person'>
print(p1 is p2)  # False
```

每次实例化都会创建一个新的对象。对象的默认字符串表示通常包含类型名和内存地址，内存地址会因运行环境而变化，不应写死在示例输出中。

## 实例方法

定义在类中的函数称为方法。实例方法的第一个参数通常命名为 `self`，它指向调用该方法的实例。

```python
class Person:
    def study(self):
        print("爱学习")


p1 = Person()
p1.study()  # 爱学习
```

调用 `p1.study()` 时，Python 会自动把 `p1` 传给 `self`。`self` 只是约定俗成的名称，并非语法强制要求，但不建议改成其他名称。

## 类属性和实例属性

### 类属性

定义在类中、方法外的属性称为类属性。类属性由类及其对象共享。

```python
class Person:
    species = "人类"


print(Person.species)    # 人类
print(Person().species)  # 人类
```

通过实例给同名属性赋值时，会创建或修改实例属性，不会修改类属性：

```python
class Person:
    species = "人类"


p1 = Person()
p2 = Person()
p1.species = "学生"

print(p1.species)      # 学生
print(p2.species)      # 人类
print(Person.species)  # 人类
```

### 实例属性

在实例方法中通过 `self` 定义的属性称为实例属性，每个实例各自拥有一份。

```python
class Person:
    def __init__(self, name):
        self.name = name


p1 = Person("张三")
p2 = Person("李四")

print(p1.name)  # 张三
print(p2.name)  # 李四
```

## 初始化方法 `__init__`

`__init__` 是对象创建后自动调用的初始化方法，常被称为构造函数，用于设置实例的初始状态。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def study(self):
        print(f"{self.name}爱学习")


p1 = Person("张三", 18)
p2 = Person("李四", 20)

p1.study()  # 张三爱学习
p2.study()  # 李四爱学习
```

严格来说，创建实例由 `__new__` 完成，`__init__` 负责初始化实例。基础学习阶段通常只需要掌握 `__init__`。

## 析构方法 `__del__`

`__del__` 在对象被回收前可能被调用，但调用时机受引用关系、垃圾回收机制和解释器退出过程影响，不能依赖它执行关键逻辑。

```python
class Resource:
    def __del__(self):
        print("对象即将被回收")
```

> 注意：文件、网络连接等资源应使用上下文管理器（`with`）或显式的关闭方法管理，不要把资源清理依赖在 `__del__` 上。

## 字符串表示 `__str__`

定义 `__str__` 可以自定义对象传给 `str()` 或 `print()` 时的字符串表示。该方法必须返回字符串。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"Person(name={self.name}, age={self.age})"


p1 = Person("张三", 18)
print(p1)  # Person(name=张三, age=18)
```

# 封装

## 含义

封装是把属性和方法组织在类中，并通过公开方法控制数据的访问和修改。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def say_hello(self):
        print(f"你好，我是{self.name}，今年{self.age}岁")


p1 = Person("张三", 18)
p1.say_hello()
p1.age = 20  # 公共属性可以直接修改
```

## 私有属性

Python 没有像某些语言那样的严格私有修饰符。以双下划线 `__` 开头的属性或方法会触发名称改写，主要用于避免外部直接访问和子类中的命名冲突。

```python
class Person:
    def __init__(self, age):
        self.__age = age

    def get_age(self):
        return self.__age

    def set_age(self, age):
        if age >= 0:
            self.__age = age


p1 = Person(18)
print(p1.get_age())  # 18
p1.set_age(20)
print(p1.get_age())  # 20

# print(p1.__age)  # AttributeError
```

名称改写后，`__age` 实际上类似于 `_Person__age`。虽然可以通过这个名称访问，但不建议这样做，因为它会破坏封装。

# 继承

## 含义

继承用于建立类与类之间的层次关系。子类可以复用父类中可访问的属性和方法，并添加自己的成员。

语法格式：

```python
class 子类(父类):
    类体
```

如果没有显式指定父类，Python 类默认直接或间接继承自 `object`。

## 单继承

一个子类只继承一个父类，称为单继承。

```python
class Person:
    kind = "人类"

    def __init__(self, name):
        self.name = name

    def greet(self):
        print(f"你好，我是{self.name}。")


class Student(Person):
    pass


student = Student("张三")
student.greet()      # 你好，我是张三。
print(Student.kind)  # 人类
```

## 继承的传递性

如果 `A` 继承 `B`，`B` 又继承 `C`，那么 `A` 可以使用 `B` 和 `C` 中可访问的成员。

```python
class C:
    def c_method(self):
        print("C")


class B(C):
    def b_method(self):
        print("B")


class A(B):
    def a_method(self):
        print("A")


a = A()
a.a_method()  # A
a.b_method()  # B
a.c_method()  # C
```

## 方法重写

子类定义与父类同名的方法，会覆盖父类的同名方法，这称为方法重写。

```python
class Parent:
    def show(self):
        print("Parent")


class Child(Parent):
    def show(self):
        print("Child")


Child().show()  # Child
```

如果需要保留父类方法的功能，可以使用 `super()` 调用父类实现，再添加子类逻辑：

```python
class Parent:
    def show(self):
        print("Parent")


class Child(Parent):
    def show(self):
        super().show()
        print("Child")


Child().show()
# Parent
# Child
```

## Python 3 的类

Python 3 中所有类默认都是新式类，都直接或间接继承自 `object`。通常直接使用下面的写法即可：

```python
class Person:
    pass
```

`class Person(object)` 在 Python 3 中也可以运行，但一般没有必要专门写出 `object`。

# 多继承和多态

## 多继承

一个子类同时继承多个父类，称为多继承。

```python
class ParentA:
    def a_method(self):
        print("A")


class ParentB:
    def b_method(self):
        print("B")


class Child(ParentA, ParentB):
    pass


child = Child()
child.a_method()  # A
child.b_method()  # B
```

### 方法解析顺序 MRO

当多个父类中存在同名方法时，Python 按方法解析顺序（MRO）查找方法：先查当前类，再按继承列表从左到右查找父类。

```python
class A:
    def show(self):
        print("A")


class B(A):
    def show(self):
        print("B")


class C(A):
    def show(self):
        print("C")


class D(B, C):
    pass


D().show()  # B
print(D.__mro__)  # D, B, C, A, object
```

`super()` 会按照当前类的 MRO 查找下一个实现。多继承结构较复杂，使用时应保持清晰，避免父类之间出现难以理解的同名成员冲突。

## 多态

多态是指同一个方法调用作用于不同类型的对象时，表现出不同的行为。调用方只需要关心对象能否提供所需的方法，不必关心对象的具体类型。

```python
class Dog:
    def speak(self):
        print("汪汪汪")


class Cat:
    def speak(self):
        print("喵喵喵")


def animal_speak(animal):
    animal.speak()


animal_speak(Dog())  # 汪汪汪
animal_speak(Cat())  # 喵喵喵
```

Python 的多态通常依赖“鸭子类型”：只要对象具有需要的方法，就可以传入使用，不要求它们必须继承同一个父类。

# 静态方法和类方法

## 静态方法 `staticmethod`

使用 `@staticmethod` 定义静态方法。静态方法不自动接收实例参数 `self` 或类参数 `cls`，适合放置与类相关但不依赖对象状态的工具函数。

```python
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b


print(MathUtils.add(3, 5))  # 8
```

静态方法通常通过类名调用；实例也可以调用，但通过类名调用更清晰。

## 类方法 `classmethod`

使用 `@classmethod` 定义类方法。类方法的第一个参数通常命名为 `cls`，指向当前类，而不是某个实例。

```python
class Person:
    count = 0

    def __init__(self, name):
        self.name = name
        Person.count += 1

    @classmethod
    def get_count(cls):
        return cls.count


Person("张三")
Person("李四")
print(Person.get_count())  # 2
```

类方法还可以作为替代构造方法，从其他数据格式创建对象：

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_text(cls, text):
        name, age = text.split(",")
        return cls(name, int(age))


p1 = Person.from_text("张三,18")
print(p1.name, p1.age)  # 张三 18
```

## 三类方法对比

| 方法类型 | 第一个参数 | 主要用途 |
| --- | --- | --- |
| 实例方法 | `self` | 访问实例属性和实例行为 |
| 类方法 | `cls` | 访问类属性或提供替代构造方法 |
| 静态方法 | 无 | 提供与类相关的工具函数 |

# 抽象基类 `abc`

抽象基类用于规定子类必须实现的方法。它适合定义统一接口，配合多态使用。

## 基本用法

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @abstractmethod
    def area(self):
        """计算面积"""
        pass


class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height


rectangle = Rectangle(3, 4)
print(rectangle.area())  # 12
# Shape()  # TypeError：抽象类不能直接实例化
```

`ABC` 是定义抽象基类的辅助类，`@abstractmethod` 用于标记抽象方法。子类如果没有实现全部抽象方法，就不能实例化。

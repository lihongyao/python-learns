# 面向对象

## 含义

面向对象将数据与操作数据的行为组织在对象中，通过对象之间的协作完成任务。

- **面向过程**：围绕处理步骤组织函数。
- **面向对象**：围绕状态与行为组织类和对象。

两种方式可以混用；简单的数据处理不必为了面向对象而额外定义类。

## 三大特性

| 特性 | 核心含义 |
| --- | --- |
| 封装 | 将数据与行为组织在一起，通过明确的接口维护对象状态 |
| 继承 | 在已有类型基础上扩展或重写行为 |
| 多态 | 相同的调用方式作用于不同对象，表现出不同的行为 |

# 类与对象

## 定义类与创建实例

类定义一种类型，对象是该类型的实例。Python 中的函数、模块和类本身也都是对象。

类名通常使用大驼峰（`CapWords`），属性和方法名通常使用 `snake_case`：

```python
class Person:
    """保存姓名并提供问候行为。"""

    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"你好，我是{self.name}"


person = Person("张三")
print(person.name)     # 张三
print(person.greet())  # 你好，我是张三
```

`class` 语句执行时会执行类体并创建类对象；方法体在调用方法时执行。没有显式指定父类的普通类默认继承 `object`，无需再区分“新式类”和“旧式类”。

## 初始化方法 `__init__`

- `__new__` 负责创建实例，通常不需要重写。
- `__init__` 在实例创建后初始化状态，不能返回非 `None` 的值。
- 子类重写 `__init__` 后，不会自动执行父类的 `__init__`，需要时使用 `super().__init__(...)`。

`alias = person` 不会创建新实例，只会共享同一对象；复制规则见[深浅拷贝](<../001_语法基础/第10章 深浅拷贝.md>)。

## 实例方法与 `self`

实例方法的第一个参数通常写作 `self`，表示当前实例。`self` 是命名约定，不是关键字。

对普通实例方法而言，`person.greet()` 相当于 `Person.greet(person)`；通过实例访问方法时，Python 会自动绑定这个实例。

方法内访问属性应使用 `self.name`；类体不是方法内可以直接查找类属性的外层函数作用域。

# 类属性和实例属性

## 基本区别

| 类型 | 常见定义方式 | 用途 |
| --- | --- | --- |
| 类属性 | 类体中赋值，如 `species = "人类"` | 保存共享状态或类级配置 |
| 实例属性 | `self.name = name` | 保存每个对象自己的状态 |

对普通属性，实例中有同名属性时会遮蔽类属性。通过实例赋值通常创建或修改实例属性，不会修改类属性：

```python
class Person:
    species = "人类"


first = Person()
second = Person()
first.species = "学生"

print(first.species)   # 学生
print(second.species)  # 人类
print(Person.species)  # 人类
```

删除 `first.species` 后，再访问会重新找到类属性。`property` 等描述器可以接管属性访问，不能把上述规则当作所有属性的完整查找顺序。

## 可变类属性的共享问题

类属性中的列表、字典等对象会被实例共享；原地修改与给实例属性重新赋值不同：

```python
class Team:
    members = []


first = Team()
second = Team()
first.members.append("张三")
print(second.members)  # ['张三']
```

每个实例需要独立的数据时，应在 `__init__` 中创建：

```python
class Team:
    def __init__(self):
        self.members = []
```

实例属性同样只是对象引用；若把同一个列表传给多个实例，它们仍可能共享数据。

# 封装

## 属性命名约定

Python 不使用 `public`、`private` 等访问修饰符：

| 写法 | 含义 |
| --- | --- |
| `name` | 公开接口，可以正常访问 |
| `_name` | 约定供内部使用，不强制限制访问 |
| `__name` | 触发名称改写，主要避免子类意外覆盖同名成员 |
| `__name__` | 系统定义的特殊名称，不应随意自创 |

类 `Person` 中的 `__age` 会被改写为类似 `_Person__age` 的名称，这不是安全隔离机制。通常优先使用公开属性或单下划线约定。

## 属性管理 `property`

直接暴露普通数据时不必机械编写 getter/setter；需要校验、计算或只读访问时使用 `property`。

```python
class Person:
    def __init__(self, age):
        self.age = age  # 初始化也经过 setter 校验

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("年龄不能为负数")
        self._age = value


person = Person(18)
person.age = 20
print(person.age)  # 20
# person.age = -1  # ValueError
```

访问方式仍是 `person.age`，无需调用 `person.age()`。只定义 getter 时，该属性不能直接赋值；这不代表整个实例或其内部数据都不可修改。

# 继承

## 单继承与方法重写

子类可以继承基类行为，定义同名方法时重写对应实现。继承关系可跨多层传递：

```python
class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"你好，我是{self.name}"


class Student(Person):
    def __init__(self, name, student_id):
        super().__init__(name)
        self.student_id = student_id

    def greet(self):
        return f"{super().greet()}，学号{self.student_id}"


student = Student("张三", "S001")
print(student.greet())  # 你好，我是张三，学号S001
print(isinstance(student, Person))  # True
print(issubclass(Student, Person))  # True
```

`isinstance(obj, Class)` 包含子类判断；`type(obj) is Class` 只检查实际类型。父类中通过 `self.method()` 调用方法时，也可能执行子类重写后的实现。

## 继承与组合

继承适合表达“是一种”的关系，例如学生是一种人。若只是对象内部需要使用另一个对象，例如汽车拥有发动机，通常用实例属性持有它，即组合。

不要仅为了复用少量代码就建立复杂的继承层次；依赖关系简单时，函数或组合通常更清晰。

# 多继承和多态

## 多继承与 MRO

`class Child(BaseA, BaseB)` 可以继承多个基类。方法解析顺序（MRO）由 C3 线性化算法确定，不能简单理解为深度优先或逐个遍历父类。

下面的例子同时说明 MRO 和 `super()` 的协作调用：

```python
class A:
    def show(self):
        return ["A"]


class B(A):
    def show(self):
        return ["B"] + super().show()


class C(A):
    def show(self):
        return ["C"] + super().show()


class D(B, C):
    pass


print([cls.__name__ for cls in D.__mro__])  # ['D', 'B', 'C', 'A', 'object']
print(D().show())                           # ['B', 'C', 'A']
```

- `super()` 按当前实例所属类的 MRO，从定义该方法的类之后继续查找，不是固定调用“直接父类”。这里 `B.show()` 中的 `super()` 会找到 `C.show()`。
- 协作式多继承要求参与的方法具有兼容的参数约定，并按设计继续调用 `super()`。
- 不能形成一致 MRO 的继承关系会在创建类时抛出 `TypeError`。

## 多态与鸭子类型

调用方关注对象能否提供所需行为，不必要求对象继承同一个父类：

```python
class Dog:
    def speak(self):
        return "汪汪"


class Cat:
    def speak(self):
        return "喵喵"


def speak(animal):
    return animal.speak()


print(speak(Dog()))  # 汪汪
print(speak(Cat()))  # 喵喵
```

这称为鸭子类型。它并非不需要接口约定，而是通过对象支持的操作来使用它。

# 静态方法和类方法

## 三类方法对比

| 方法类型 | 自动接收的参数 | 典型用途 |
| --- | --- | --- |
| 实例方法 | 实例 `self` | 读取或修改实例状态 |
| `@classmethod` | 调用时绑定的类 `cls` | 替代构造方法、类级操作 |
| `@staticmethod` | 无 | 与类相关且不依赖实例或类状态的函数 |

## 类方法 `classmethod`

替代构造方法使用 `cls(...)` 创建对象，便于继承后仍返回对应子类的实例：

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_text(cls, text):
        name, age = text.split(",")
        return cls(name, int(age))


person = Person.from_text("张三,18")
print(person.name, person.age)  # 张三 18
```

通过子类调用时，`cls` 是该子类；前提是子类构造方法兼容传入的参数。通过 `cls.attr = value` 赋值时，也可能在子类上创建同名类属性。

## 静态方法 `staticmethod`

```python
class MathUtils:
    @staticmethod
    def add(a, b):
        return a + b


print(MathUtils.add(3, 5))  # 8
```

类和实例都能调用静态方法，通常通过类调用更清晰。与类关系不紧密的工具函数直接定义在模块中即可。

# 常用特殊方法

特殊方法让自定义对象接入 Python 的内置操作，通常通过对应语法调用：

| 方法 | 对应操作或用途 |
| --- | --- |
| `__init__` | 初始化实例 |
| `__repr__` | `repr(obj)`、交互调试以及容器中元素的表示 |
| `__str__` | `str(obj)`、`print(obj)` |
| `__eq__` | `obj == other` |
| `__hash__` | `hash(obj)`，用于字典键和集合元素 |
| `__len__` | `len(obj)` |
| `__bool__` | `bool(obj)`、条件判断 |
| `__iter__` | `iter(obj)`、`for` 遍历 |
| `__getitem__` | `obj[key]` |
| `__call__` | `obj(...)` |
| `__enter__`、`__exit__` | `with` 上下文管理 |

## `__repr__` 与 `__str__`

`__repr__` 面向调试，应尽量明确；`__str__` 面向展示。两者都必须返回字符串；没有自定义 `__str__` 时，会回退到 `__repr__`。

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point(x={self.x!r}, y={self.y!r})"

    def __str__(self):
        return f"({self.x}, {self.y})"


point = Point(1, 2)
print(point)        # (1, 2)
print(repr(point))  # Point(x=1, y=2)
print([point])      # [Point(x=1, y=2)]
```

## 相等与哈希

- `is` 判断是否为同一对象，不受 `__eq__` 影响；`==` 按相等比较协议处理。
- 没有自定义相等比较的普通类，实例通常按身份比较。
- 定义 `__eq__` 却未提供合适的 `__hash__` 时，类通常变为不可哈希。
- 可哈希对象必须满足“相等对象的哈希值相同”，且哈希值在其生命周期内不变；可变对象一般不宜按可变字段计算哈希。

## 资源清理与 `__del__`

`del obj` 删除的是名称绑定，不保证立即销毁对象或调用 `__del__`。不要依赖 `__del__` 的调用时机处理关键逻辑；文件、连接等资源优先使用 `with` 或显式 `close()`。

# 抽象基类 `abc`

需要明确约束子类接口时，可使用 `ABC` 和 `@abstractmethod`：

```python
from abc import ABC, abstractmethod


class Shape(ABC):
    @abstractmethod
    def area(self):
        """返回面积。"""


class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height


print(Rectangle(3, 4).area())  # 12
# Shape()  # TypeError：仍有未实现的抽象方法
```

- 普通子类仍有未实现的抽象方法或抽象属性时，不能实例化；仅继承 `ABC` 不会自动使类不可实例化。
- 抽象方法可以包含实现，供子类通过 `super()` 复用。
- 与 `@classmethod`、`@staticmethod` 或 `@property` 组合时，`@abstractmethod` 放在最内层，即最靠近 `def`。

# 数据类 `dataclass`

主要用于保存数据的类，可用 `@dataclass` 自动生成初始化、调试表示和相等比较等方法：

```python
from dataclasses import dataclass, field


@dataclass
class User:
    name: str
    tags: list[str] = field(default_factory=list)


first = User("张三")
second = User("李四")
first.tags.append("管理员")
print(first)        # User(name='张三', tags=['管理员'])
print(second.tags)  # []
```

- 可变字段的默认值使用 `field(default_factory=...)`，让每个实例独立创建对象。
- 类型注解不提供自动的运行时校验；需要额外初始化或校验时，可定义 `__post_init__`。
- `frozen=True` 限制普通字段赋值，不会递归冻结列表等内部对象。
- 默认 `eq=True, frozen=False` 的数据类实例不可哈希，不要直接用作字典键或集合元素。
- `slots=True` 可生成槽位，适合字段固定的场景，使用前应考虑继承和动态属性需求。

# 属性访问与 `__slots__`

## 属性操作

| 函数 | 作用 |
| --- | --- |
| `getattr(obj, name[, default])` | 按名称读取属性，可指定缺失时的默认值 |
| `setattr(obj, name, value)` | 按名称设置属性 |
| `hasattr(obj, name)` | 判断属性访问是否成功，内部会捕获 `AttributeError` |
| `delattr(obj, name)` | 按名称删除属性 |

这些操作也可能触发 `property` 等属性访问逻辑，不是单纯读写字典。普通实例通常可以动态添加属性；类注解本身不限制属性集合。

## `__slots__`（了解）

在类中声明 `__slots__ = ("name", "age")` 可为指定属性预留槽位，在满足条件时省去实例的 `__dict__`，减少大量实例的内存开销。

- 它不是访问控制机制，也不自动校验类型。
- 基类已有实例 `__dict__`，或子类没有继续声明 `__slots__` 时，实例仍可能支持动态属性。
- 若基类未提供弱引用支持，需要时可将 `"__weakref__"` 加入槽位；数据类可使用 `slots=True, weakref_slot=True`。

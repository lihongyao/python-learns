# 进程介绍

## 含义

进程是正在运行的程序，是操作系统进行资源分配的基本单位。每个进程都有独立的地址空间、文件描述符等资源。

一个进程至少包含一个线程，该线程通常称为主线程；一个进程也可以创建多个线程。线程不能脱离进程单独存在。

与线程相比，进程之间默认不共享普通变量，彼此隔离性更强，但创建和通信的开销也更大。

## 进程状态

进程在运行过程中通常会经历以下状态：

- **新建态**：进程刚被创建。
- **就绪态**：已经具备运行条件，等待操作系统调度。
- **运行态**：正在占用 CPU 执行代码。
- **阻塞态**：正在等待 I/O、锁或其他事件。
- **终止态**：程序执行结束或被终止。

# 多进程

Python 使用 `multiprocessing` 模块创建和管理进程。`Process` 对象中的目标函数会在独立的子进程中执行。

## `Process` 常用参数

| 参数 | 含义 |
| --- | --- |
| `target` | 子进程启动后执行的函数。传入函数名，不要写成函数调用。 |
| `args` | 以元组形式传递位置参数。 |
| `kwargs` | 以字典形式传递关键字参数。 |
| `name` | 设置进程名称，便于调试。 |

常用方法和属性：

- `start()`：启动子进程。
- `join(timeout=None)`：等待子进程结束。
- `is_alive()`：判断子进程是否仍在运行。
- `pid`：子进程的进程编号。
- `name`：进程名称。

## 创建进程

```python
from multiprocessing import Process, current_process


def task(name):
    process = current_process()
    print(f"{name}：进程名={process.name}，PID={process.pid}")


if __name__ == "__main__":
    p1 = Process(target=task, name="process-1", args=("任务一",))
    p2 = Process(target=task, name="process-2", kwargs={"name": "任务二"})

    p1.start()
    p2.start()

    p1.join()
    p2.join()

    print(p1.is_alive())  # False
    print(p2.is_alive())  # False
```

两个子进程都启动后再调用 `join()`，它们可以并行执行。多个进程的输出顺序由操作系统调度决定，不能写死。

> 注意：`if __name__ == "__main__":` 在 Windows 和使用 `spawn` 启动方式的系统上尤其重要，可以避免子进程重复执行创建进程的代码。

## 进程参数传递

和线程类似，进程可以使用 `args` 或 `kwargs` 传递参数：

```python
from multiprocessing import Process


def greet(name, message):
    print(f"{name}：{message}")


if __name__ == "__main__":
    p1 = Process(target=greet, args=("张三", "你好"))
    p2 = Process(
        target=greet,
        kwargs={"name": "李四", "message": "欢迎学习 Python"},
    )

    p1.start()
    p2.start()
    p1.join()
    p2.join()
```

# 进程间通信

## 普通变量不共享

进程拥有相互独立的内存空间。即使多个进程使用同名的全局变量，修改也不会自动同步：

```python
from multiprocessing import Process


data = []


def write_data():
    data.extend([1, 2, 3])
    print(f"子进程中的数据：{data}")


def read_data():
    print(f"另一个进程中的数据：{data}")


if __name__ == "__main__":
    writer = Process(target=write_data)
    reader = Process(target=read_data)

    writer.start()
    writer.join()
    reader.start()
    reader.join()

    print(f"主进程中的数据：{data}")
```

即使等待写入进程结束，其他进程和主进程中的 `data` 也不会自动变成 `[1, 2, 3]`。需要使用队列、管道、共享内存等进程间通信机制交换数据。

## `Queue` 队列

`multiprocessing.Queue` 用于在多个进程之间安全传递可序列化的数据。

常用方法：

- `put(item)`：向队列中放入数据。
- `get()`：从队列中取出数据；队列为空时默认阻塞等待。
- `empty()`：判断队列是否为空。
- `qsize()`：获取队列中大致的元素数量。
- `full()`：判断队列是否已满。

> 注意：在多进程并发环境中，`empty()`、`qsize()` 和 `full()` 的结果可能在返回后立即变化，不能用它们可靠地判断“是否已经读完”。常用做法是发送一个特殊的结束标记（哨兵值）。

## 使用队列通信

```python
from multiprocessing import Process, Queue


def producer(queue):
    for item in ["张三", "李四", "王五"]:
        queue.put(item)
    queue.put(None)  # 通知消费者：数据发送完毕


def consumer(queue):
    while True:
        item = queue.get()
        if item is None:
            break
        print(f"收到数据：{item}")


if __name__ == "__main__":
    queue = Queue()
    p1 = Process(target=producer, args=(queue,))
    p2 = Process(target=consumer, args=(queue,))

    p2.start()
    p1.start()
    p1.join()
    p2.join()
```

队列中的数据会通过进程间通信传递，写入队列的对象会被序列化，取出后得到等价但不一定是同一个内存对象。

## 队列容量

创建队列时可以通过 `maxsize` 设置容量：

```python
from multiprocessing import Queue


queue = Queue(maxsize=2)
queue.put("第一条")
queue.put("第二条")
print(queue.full())  # True
print(queue.get())  # 第一条
print(queue.empty())  # False
```

# 进程池

## 含义

需要执行大量相似任务时，逐个创建进程会增加管理成本。进程池预先维护一定数量的工作进程，任务完成后工作进程可以继续处理其他任务。

进程池通过 `processes` 参数限制同时运行的工作进程数量，从而控制资源使用。

## 常用方法

- `apply(func, args=())`：同步执行任务，等待任务完成并返回结果。
- `apply_async(func, args=())`：异步提交任务，返回 `AsyncResult` 对象。
- `map(func, iterable)`：按顺序执行一组任务并返回结果列表。
- `close()`：不再接受新任务，已提交的任务会继续执行。
- `join()`：等待进程池中的工作进程全部结束，必须在 `close()` 后调用。
- `AsyncResult.get()`：获取异步任务的结果，结果未准备好时会阻塞等待。

## `apply_async()` 示例

```python
from multiprocessing import Pool


def double(number):
    return number * 2


if __name__ == "__main__":
    pool = Pool(processes=3)
    results = [
        pool.apply_async(double, args=(number,))
        for number in range(5)
    ]

    pool.close()
    pool.join()

    for result in results:
        print(result.get())
```

`apply_async()` 提交任务后不会立即等待结果；调用 `get()` 时才获取对应结果。将 `close()` 放在提交任务之后，再调用 `join()` 等待所有任务完成。

# 概述

正则表达式用于按规则验证、查找、提取、替换和分割文本。Python 通过标准库 `re` 提供支持；简单场景优先使用 `in`、`startswith()`、`split()` 等字符串操作。

# 常用匹配函数

## 函数对比

| 函数 | 作用 | 返回结果 |
| --- | --- | --- |
| `match()` | 仅从字符串开头尝试匹配 | `Match` 或 `None` |
| `search()` | 查找第一个匹配 | `Match` 或 `None` |
| `fullmatch()` | 要求整个字符串匹配 | `Match` 或 `None` |
| `findall()` | 查找所有非重叠匹配 | 列表，形状受捕获组影响 |
| `finditer()` | 查找所有非重叠匹配 | `Match` 对象迭代器 |
| `sub()`、`subn()` | 替换匹配内容 | 新字符串、`(新字符串, 替换次数)` |
| `split()` | 按模式分割 | 列表，捕获组也会进入结果 |

```python
import re

print(re.match(r"\d+", "abc123"))           # None
print(re.search(r"\d+", "abc123").group())  # 123
print(bool(re.fullmatch(r"\d+", "123a")))   # False
```

真实输入可能匹配失败，调用 `group()` 前先检查是否为 `None`。零长度匹配也会返回有效的 `Match`，与未匹配不同。

## `Match` 对象

```python
import re

match = re.search(r"(?P<name>[a-z]+)-(?P<id>\d+)", "user-42")
if match is not None:
    print(match.group(0))      # user-42
    print(match.group("id"))   # 42
    print(match.groups())     # ('user', '42')
    print(match.groupdict())  # {'name': 'user', 'id': '42'}
    print(match.span())       # (0, 7)
```

`group(0)` 表示完整匹配，捕获组从 `1` 开始编号；位置范围遵循左闭右开。未参与匹配的可选组通常为 `None`。

## `findall()` 与捕获组

```python
import re

text = "A1 B2"
print(re.findall(r"[A-Z]\d", text))        # ['A1', 'B2']
print(re.findall(r"[A-Z](\d)", text))      # ['1', '2']
print(re.findall(r"([A-Z])(\d)", text))    # [('A', '1'), ('B', '2')]
```

没有捕获组时返回完整匹配；一个捕获组时返回该组；多个捕获组时返回元组。只需要分组、不需要提取时使用 `(?:...)`。

# 基础语法

## 原始字符串和转义

模式通常使用 `r"..."`，减少 Python 字符串与正则表达式两层转义。原始字符串不会关闭正则自身的转义规则。

```python
import re

print(bool(re.fullmatch(r"a\.b", "a.b")))           # True
print(re.findall(re.escape("a+b"), "a+b aab"))      # ['a+b']
```

`re.escape()` 用于把动态文本作为字面量放入模式，不用于转义 `sub()` 的替换字符串。模式、输入和替换内容的 `str`、`bytes` 类型不能混用。

## 字符集合与元字符

| 写法 | 含义 |
| --- | --- |
| `[abc]`、`[a-z]` | 集合中一个字符、范围内一个字符 |
| `[^abc]` | 不在集合中的一个字符 |
| `.` | 默认匹配除换行符外的一个字符 |
| `\d`、`\D` | Unicode 十进制数字、其补集 |
| `\w`、`\W` | Unicode 字母数字与下划线、其补集 |
| `\s`、`\S` | Unicode 空白字符、其补集 |

`[0-9]` 只匹配 ASCII 数字；`\d` 默认不限于 `0`～`9`。`re.ASCII` 可缩小字符串模式中 `\d`、`\w`、`\s` 等字符类的范围。

字符集合内多数元字符不再特殊，但 `]`、`-`、`^`、`\` 仍需按位置和含义处理。

## 重复限定符

| 量词 | 重复次数 |
| --- | --- |
| `?` | 0 或 1 次 |
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n～m 次，包含两端 |

量词作用于前面的字符、字符集合或分组，不是自动作用于整个模式。

## 定位符

| 写法 | 含义 |
| --- | --- |
| `^` | 字符串开头，`re.M` 下还匹配每行开头 |
| `$` | 字符串末尾或末尾换行前，`re.M` 下还匹配每行结尾 |
| `\A`、`\z` | 严格的字符串开头、末尾，不受 `re.M` 影响 |
| `\b` | `\w` 与 `\W` 之间，或符合条件的字符串边界 |
| `\B` | 不处于单词边界的位置 |

`\z` 自 Python 3.14 提供；`\Z` 与其同义。整体校验优先使用 `fullmatch()`，避免误解 `$` 对末尾换行的处理。`re.M` 不会让 `match()` 自动搜索每行开头。

## 选择与分组

- `A|B`：按从左到右的顺序尝试分支，一旦匹配就接受，不保证选择最长分支。
- `(pattern)`：捕获组。
- `(?P<name>pattern)`：命名捕获组。
- `(?:pattern)`：非捕获组。
- `\1`、`(?P=name)`：匹配前面捕获组已经匹配到的相同文本。

```python
import re

print(re.search(r"a|ab", "ab").group())                  # a
print(bool(re.fullmatch(r"(?P<word>\w+)\s+(?P=word)", "hi hi")))  # True
```

## 前后查找断言

断言只检查条件，不消耗输入字符：

| 写法 | 条件 |
| --- | --- |
| `(?=...)`、`(?!...)` | 后面符合、不符合模式 |
| `(?<=...)`、`(?<!...)` | 前面符合、不符合模式 |

`re` 的后行断言要求内部模式长度固定。

```python
import re

print(re.search(r"\d+(?=元)", "价格20元").group())   # 20
print(re.search(r"(?<=编号:)\d+", "编号:42").group())  # 42
```

## 贪婪、非贪婪与占有量词

- 默认量词是贪婪的，尽量多匹配，必要时回溯。
- 量词后加 `?`，如 `*?`、`+?`，尽量少匹配，但仍需满足后续模式。
- Python 3.11 起支持占有量词，如 `*+`、`++`，匹配后不回溯；原子组 `(?>...)` 也可阻止退出组后回溯其内部。

```python
import re

text = "<a>内容<b>"
print(re.findall(r"<.*>", text))   # ['<a>内容<b>']
print(re.findall(r"<.*?>", text))  # ['<a>', '<b>']
```

非贪婪不等于更快。避免 `(a+)+` 等可能产生大量回溯的模式；结构化数据应优先使用专门的解析器。

# 替换与分割

```python
import re

print(re.sub(r"(?P<key>\w+)=(\d+)", r"\g<key>:\2", "age=18"))  # age:18
print(re.subn(r"\d+", "#", "A1 B2"))                          # ('A# B#', 2)
print(re.split(r"([,;])", "a,b;c"))                           # ['a', ',', 'b', ';', 'c']
```

- 替换字符串推荐用 `\g<1>`、`\g<name>` 引用分组，避免 `\10` 等歧义。
- `re.sub()` 的 `repl` 也可以是接收 `Match` 并返回字符串的函数。
- 使用 `count=` 限制替换次数，使用 `maxsplit=` 限制分割次数；显式写关键字，避免已弃用的位置传参形式。

# 编译与匹配标志

`re.compile()` 返回可复用的模式对象。模块级函数也会缓存最近使用的模式，不应简单断言每次匹配都必须手动编译。

```python
import re

pattern = re.compile(r"python", flags=re.I)
print(pattern.findall("Python PYTHON"))  # ['Python', 'PYTHON']
```

| 标志 | 用途 |
| --- | --- |
| `re.I` | 忽略大小写 |
| `re.M` | 改变 `^`、`$` 的逐行匹配行为 |
| `re.S` | 让 `.` 也匹配换行 |
| `re.X` | 允许模式中的注释和排版空白，字符集合内及转义空白除外 |
| `re.A` | 对相关字符类使用 ASCII 规则 |

标志可使用 `|` 组合。模式语法无效会抛出 `re.PatternError`，与“匹配不到返回 `None`”不同；`re.error` 是兼容别名。

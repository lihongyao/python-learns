# 概述

## 含义

正则表达式（Regular Expression）是一种描述字符串匹配规则的文本模式，可以用于查找、验证、提取、替换和分割文本。

Python 通过标准库中的 `re` 模块提供正则表达式功能：

```python
import re
```

正则表达式功能强大，但语法相对复杂。对于简单的字符串处理，应优先考虑字符串的 `in`、`startswith()`、`split()` 等方法。

## 基本步骤

1. 导入 `re` 模块。
2. 编写正则表达式模式。
3. 调用匹配、查找、替换或分割函数。
4. 根据返回结果处理匹配内容。

```python
import re


result = re.match(r"h", "hello")
if result:
    print(result.group())  # h
else:
    print("匹配失败")
```

`match()` 匹配失败时返回 `None`。调用 `group()`、`groups()` 等方法前，应先确认匹配对象不是 `None`。

# 常用匹配函数

## `match()`、`search()` 和 `fullmatch()`

| 函数 | 作用 | 返回值 |
| --- | --- | --- |
| `re.match(pattern, string)` | 只从字符串开头匹配 | 第一个 `Match` 对象或 `None` |
| `re.search(pattern, string)` | 在整个字符串中查找第一个匹配 | 第一个 `Match` 对象或 `None` |
| `re.fullmatch(pattern, string)` | 要求整个字符串完全匹配 | `Match` 对象或 `None` |

```python
import re


print(re.match(r"\d+", "123abc").group())  # 123
print(re.search(r"\d+", "abc123def").group())  # 123
print(re.fullmatch(r"\d+", "123").group())  # 123
```

如果不能确定是否匹配成功，应使用条件判断：

```python
import re


result = re.search(r"\d+", "hello")
if result:
    print(result.group())
else:
    print("没有找到匹配内容")
```

## `findall()` 和 `finditer()`

- `re.findall(pattern, string)`：返回所有非重叠匹配的列表。
- `re.finditer(pattern, string)`：返回一个迭代器，迭代得到 `Match` 对象，适合同时获取匹配位置。

```python
import re


text = "123abc456def"
print(re.findall(r"\d+", text))  # ['123', '456']

for match in re.finditer(r"\d+", text):
    print(match.group(), match.span())
# 123 (0, 3)
# 456 (6, 9)
```

> 注意：正则表达式中包含捕获组时，`findall()` 返回的可能是捕获组内容，而不是完整匹配内容，详见“捕获分组”。

## `sub()` 和 `split()`

- `re.sub(pattern, repl, string)`：将所有匹配内容替换为 `repl`。
- `re.split(pattern, string)`：按照匹配内容分割字符串。

```python
import re


text = "123abc456def"
print(re.sub(r"\d+", "NUM", text))  # NUMabcNUMdef
print(re.split(r"\d+", text))  # ['', 'abc', 'def']
```

## `compile()` 和 flags

`re.compile()` 可以预编译正则表达式，适合重复使用同一个模式：

```python
import re


pattern = re.compile(r"\d+")
print(pattern.findall("123abc456def"))  # ['123', '456']
print(pattern.search("abc123").group())  # 123
```

常用 flags：

| 标志 | 含义 |
| --- | --- |
| `re.I` 或 `re.IGNORECASE` | 忽略大小写 |
| `re.M` 或 `re.MULTILINE` | 让 `^` 和 `$` 匹配每一行的开头和结尾 |
| `re.S` 或 `re.DOTALL` | 让 `.` 也可以匹配换行符 |
| `re.X` 或 `re.VERBOSE` | 允许使用空白和注释编写更易读的模式 |

```python
import re


print(re.search(r"python", "Python", re.I).group())  # Python
```

# 基础语法

## 原始字符串和转义

正则表达式中反斜杠 `\` 用于表示特殊含义，例如 `\d` 表示数字。Python 字符串本身也使用反斜杠表示转义，因此正则表达式通常使用原始字符串 `r"..."` 编写，以减少转义层次。

```python
import re


text = "abc$def(123)"
print(re.findall(r"\(123\)", text))  # ['(123)']
```

常见需要转义的正则字符包括：`. * + ? ^ $ ( ) [ ] { } | \`。

## 字符集合

字符集合用方括号 `[]` 表示，匹配其中的任意一个字符。

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `[abc]` | 匹配 `a`、`b` 或 `c` 中的一个字符 | `a` |
| `[^abc]` | 匹配不在集合中的一个字符 | `d` |
| `[a-z]` | 匹配 `a` 到 `z` 范围内的一个字符 | `m` |
| `[0-9]` | 匹配 `0` 到 `9` 范围内的一个数字 | `5` |

## 常用元字符

| 元字符 | 含义 |
| --- | --- |
| `.` | 匹配除换行符外的任意单个字符 |
| `\d` | 匹配一个数字；默认支持 Unicode 数字 |
| `\D` | 匹配一个非数字字符 |
| `\s` | 匹配空白字符，如空格、制表符和换行符 |
| `\S` | 匹配非空白字符 |
| `\w` | 匹配 Unicode 字母、数字、下划线等“单词字符” |
| `\W` | 匹配非单词字符 |

如果需要只匹配 ASCII 字符，可以使用 `re.ASCII` 标志。

## 重复限定符

量词作用于它前面的一个字符、字符集合或分组，用于指定连续出现次数：

| 量词 | 含义 |
| --- | --- |
| `?` | 0 次或 1 次 |
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次，包含两端 |

```python
import re


text = "a aa aaa"
print(re.findall(r"a{2,3}", text))  # ['aa', 'aaa']
```

## 定位符

定位符指定匹配内容所在的位置：

| 定位符 | 含义 |
| --- | --- |
| `^` | 字符串或行的开头 |
| `$` | 字符串或行的结尾 |
| `\b` | 单词边界，即 `\w` 和 `\W` 的交界处或字符串首尾 |
| `\B` | 非单词边界 |

```python
import re


print(bool(re.fullmatch(r"\d+", "123")))  # True
print(bool(re.fullmatch(r"\d+", "123a")))  # False
```

## 选择匹配

竖线 `|` 表示多个模式中的任意一个：

```python
import re


text = "土豆和马铃薯是同一种东西"
print(re.findall(r"土豆|马铃薯", text))  # ['土豆', '马铃薯']
```

## 分组

圆括号 `()` 可以把多个字符组合成一个整体，也可以捕获匹配内容。

### 捕获分组

普通捕获组 `(pattern)` 会保存匹配的子字符串。分组从 1 开始编号，编号 0 表示完整匹配。

```python
import re


match = re.search(r"(\d+)-(\w+)", "123-abc")
print(match.group())  # 123-abc
print(match.group(1))  # 123
print(match.group(2))  # abc
print(match.groups())  # ('123', 'abc')
```

命名捕获组使用 `(?P<name>pattern)`：

```python
import re


match = re.search(r"(?P<id>\d+)-(?P<name>\w+)", "123-abc")
print(match.group("id"))  # 123
print(match.groupdict())  # {'id': '123', 'name': 'abc'}
```

### 非捕获组

`(?:pattern)` 只进行分组和匹配，不保存分组内容，也不占用分组编号：

```python
import re


print(re.findall(r"小樱(?:同学|同志)", "小樱同学和小樱同志"))
# ['小樱同学', '小樱同志']
```

### 先行断言

先行断言只检查当前位置后面的内容，不消耗字符，因此断言内容不会出现在匹配结果中：

- `(?=pattern)`：正向先行断言，后面必须跟随 `pattern`。
- `(?!pattern)`：负向先行断言，后面不能跟随 `pattern`。

```python
import re


print(re.search(r"Harmony(?=2|3)", "Harmony2").group())  # Harmony
print(re.search(r"Harmony(?!2|3)", "Harmony1").group())  # Harmony
```

## 贪婪和非贪婪

- **贪婪模式**：默认模式，尽可能匹配更多字符。
- **非贪婪模式**：在量词后加 `?`，尽可能匹配更少字符。

```python
import re


text = "abc111111abc"
print(re.findall(r"\d{3,5}", text))   # ['11111']
print(re.findall(r"\d{3,5}?", text))  # ['111', '111']
```

# 认识集合

集合（`set`）是一种无序且不重复的可变集合类型，适合进行成员判断和集合运算。

集合使用花括号 **{ }**，元素之间使用逗号 **,** 分隔，也可以使用 `set()` 从可迭代对象创建集合。

语法格式：

```text
items = {value1, value2, ...}
items = set(iterable)
```

注意事项：

1. 集合中的元素必须唯一，重复元素会被自动去重。
2. 集合是无序的，不记录元素的位置或插入顺序，因此不能通过索引访问，也不支持切片。
3. 集合中的元素必须是可哈希对象。数字、字符串以及只包含可哈希元素的元组可以作为元素；列表、字典和集合不能作为元素。
4. `{}` 表示空字典，创建空集合必须使用 `set()`。

代码示例：

```python
numbers = {1, 2, 2, 3}
print(numbers)  # 重复的 2 会被自动去重，元素顺序可能不同

letters = set("abracadabra")
print("a" in letters)  # True
```

`set` 适合去重和频繁的成员判断。去重会丢失原顺序；需要保留首次出现顺序时，可使用 [`dict.fromkeys()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.fromkeys) 配合 [`list()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list)：

```python
items = ["A", "B", "A", "C"]
unique = list(dict.fromkeys(items))
print(unique)  # ['A', 'B', 'C']
```

# 基本使用

## 集合运算

集合支持并集、交集、差集和对称差集等运算：

```python
a = set("abracadabra")
b = set("alacazam")

# 使用 sorted() 便于稳定查看结果，返回值是列表
print(sorted(a - b))  # ['b', 'd', 'r']：差集
print(sorted(a | b))  # ['a', 'b', 'c', 'd', 'l', 'm', 'r', 'z']：并集
print(sorted(a & b))  # ['a', 'c']：交集
print(sorted(a ^ b))  # ['b', 'd', 'l', 'm', 'r', 'z']：对称差集
```

## 集合推导式

集合也支持推导式，可以根据条件快速创建集合：

```python
result = {x for x in "abracadabra" if x not in "abc"}
print(sorted(result))  # ['d', 'r']
```

# 基本操作

## 添加元素

- [`set.add(element)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.add)：添加一个元素；如果元素已存在，则不进行任何操作
- [`set.update(*others)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.update)：将一个或多个可迭代对象中的元素添加到集合中

```python
items = {"北京", "上海"}

items.add("重庆")
items.update(["广州", "深圳"])
print("重庆" in items)  # True
print(len(items))      # 5
```

`add()` 添加一个对象；`update()` 逐个添加可迭代对象中的元素。例如 `add("AB")` 添加字符串 `"AB"`，`update("AB")` 添加字符 `"A"` 和 `"B"`。

## 删除元素

- [`set.remove(element)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.remove)：删除指定元素；元素不存在时抛出 `KeyError`
- [`set.discard(element)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.discard)：删除指定元素；元素不存在时不报错
- [`set.pop()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.pop)：删除并返回任意一个元素；集合为空时抛出 `KeyError`
- [`set.clear()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.clear)：清空集合

```python
items = {"北京", "上海", "重庆"}

items.remove("上海")
items.discard("广州")
item = items.pop()
items.clear()
print(items)  # set()
```

> **注意**：集合无序，`pop()` 删除的是任意元素，不保证具体顺序。

# 集合常见操作

## 集合运算方法

- [`set.union(*others)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.union) 或 `|`：返回并集，不修改原集合
- [`set.intersection(*others)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.intersection) 或 `&`：返回交集，不修改原集合
- [`set.difference(*others)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.difference) 或 `-`：返回差集，不修改原集合
- [`set.symmetric_difference(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.symmetric_difference) 或 `^`：返回对称差集，不修改原集合

运算符形式要求两侧都是集合；方法形式允许传入列表等可迭代对象：

```python
items = {1, 2}
print(items.intersection([2, 3]))  # {2}
# items & [2, 3]  # TypeError
```

## 原地更新方法

- [`set.intersection_update(*others)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.intersection_update) 或 `&=`：仅保留交集
- [`set.difference_update(*others)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.difference_update) 或 `-=`：移除其他对象中的元素
- [`set.symmetric_difference_update(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.symmetric_difference_update) 或 `^=`：原地计算对称差集
- `update()` 或 `|=`：原地计算并集

这些方法都会修改原集合并返回 `None`；复合赋值运算符形式要求右侧为集合。

```python
items = {1, 2, 3}
items &= {2, 3, 4}
print(sorted(items))  # [2, 3]
```

## 关系判断

- [`set.issubset(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.issubset) 或 `<=`：判断当前集合是否为另一个集合的子集
- [`set.issuperset(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.issuperset) 或 `>=`：判断当前集合是否为另一个集合的超集
- [`set.isdisjoint(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.isdisjoint)：判断两个集合是否没有交集

`<` 和 `>` 分别表示真子集、真超集，要求双方不相等。集合的这些比较基于包含关系，不是比较元素个数：

```python
print({1, 2} <= {1, 2, 3})  # True
print({1, 2} < {1, 2})      # False
print({1, 2}.isdisjoint({3, 4}))  # True
```

## 其他常用方法和函数

- [`len(items)`](https://docs.python.org/zh-cn/3/library/functions.html#len)：返回集合中元素的数量
- [`value in items`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set-types-set-frozenset)：判断元素是否存在于集合中
- [`set(iterable)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set)：从可迭代对象创建集合；不传参数时创建空集合
- [`set.copy()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#set.copy)：返回集合的浅拷贝
- [`sorted(items)`](https://docs.python.org/zh-cn/3/library/functions.html#sorted)：返回排序后的列表，原集合不会改变

> **注意**：`add`、`update`、`remove`、`discard`、`pop` 和 `clear` 会直接修改原集合；集合运算方法通常返回一个新集合。

遍历集合时不要直接增删其元素；可以遍历副本，或通过集合推导式创建新集合。

# 不可变集合

[`frozenset(iterable)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#frozenset) 创建不可变集合，支持成员判断和集合运算，但没有添加、删除等修改方法。它可作为字典键或其他集合的元素。

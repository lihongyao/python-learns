# 概述

函数是封装特定功能的代码块，可以在需要时被调用，从而减少重复代码并提高复用性。

# 定义和调用函数

## 定义函数

使用 `def` 关键字定义函数，函数体必须缩进：

```python
def function_name(parameters):
    """函数的描述信息"""
    function_body
```

> **注意**：函数名应遵循标识符命名规则，并尽量做到见名知意。函数定义时不会执行函数体中的代码。

示例：

```python
def say_hello():
    print("Hello~")
    print("Nice to meet you")
```

## 调用函数

定义函数后，使用函数名和圆括号调用：

```python
function_name(arguments)
```

示例：

```python
say_hello()
```

函数可以被重复调用，调用一次就执行一次。代码通常按从上到下的顺序执行，因此调用函数前应先完成函数定义。

# 返回值

函数可以使用 `return` 将结果返回给调用者：

```text
return value
```

`return` 会立即结束当前函数的执行。函数没有显式返回值时，默认返回 `None`。

```python
def add(a, b):
    return a + b


result = add(1, 2)
print(result)  # 3


def get_user():
    return "张三", 18


name, age = get_user()  # 多个返回值会打包为元组
print(name, age)        # 张三 18
```

# 参数

## 形参与实参

- **形参**：函数定义时指定的参数，是接收数据的占位符。
- **实参**：调用函数时传入的实际值。

```python
def add(a: int, b: int):  # a、b 是形参
    return a + b


print(add(1, 2))  # 1、2 是实参
```

> **注意**：类型注解主要用于说明和工具提示，不会自动进行类型检查。

## 位置参数

按参数定义的顺序传递参数，参数数量也必须匹配：

```python
def greet(name, greeting):
    print(f"{name}, {greeting}")


greet("Alice", "Hi")  # Alice, Hi
```

如果缺少参数或传入过多位置参数，调用时会抛出 `TypeError`；参数顺序不正确则可能导致结果错误。

## 关键字参数

调用函数时，可以使用 `参数名=值` 指定参数。关键字参数不依赖位置，代码可读性更好：

```python
def greet(name, greeting):
    print(f"{name}, {greeting}")


greet(name="Alice", greeting="Hi")
greet(greeting="Hello", name="Bob")
```

位置参数和关键字参数混用时，位置参数必须放在关键字参数之前：

```python
greet("Alice", greeting="Hi")
```

## 默认参数

在定义函数时，可以为参数指定默认值。调用时省略该参数，就会使用默认值：

```python
def greet(name, greeting="Hello"):
    print(f"{name}, {greeting}")


greet("Bob")       # Bob, Hello
greet("Bob", "Hi")  # Bob, Hi
```

> **注意**：定义函数时，非默认参数必须放在默认参数之前。列表、字典等可变对象不建议直接作为默认值，因为默认值只会在函数定义时创建一次。

错误示例：

```text
def greet(greeting="Hello", name):
    print(f"{name}, {greeting}")
```

该定义会抛出 `SyntaxError`，因为非默认参数不能放在默认参数之后。

## 可变数量参数

- `*args`：接收任意数量的位置参数，参数会被收集为元组。
- `**kwargs`：接收任意数量的关键字参数，参数会被收集为字典。

```python
def describe(*args, **kwargs):
    print(args)
    print(kwargs)


describe(1, 2, name="Alice", age=30)
# (1, 2)
# {'name': 'Alice', 'age': 30}
```

# 变量作用域

变量作用域是指代码能够访问变量的范围。函数中常见的作用域包括局部作用域、外层函数作用域和全局作用域。

## 局部变量

在函数内部定义的变量是局部变量，只能在该函数内部访问：

```python
def show_message():
    message = "局部变量"
    print(message)


show_message()
# print(message)  # NameError: name 'message' is not defined
```

## 全局变量

在函数外部定义的变量是全局变量。函数可以读取全局变量，但在函数内部给变量赋值时，该变量默认会被当作局部变量：

```python
message = "全局变量"


def show_message():
    print(message)


show_message()  # 全局变量
```

> **注意**：局部变量与全局变量同名时，局部变量会遮蔽函数内部对全局变量的访问。实际开发中应尽量减少对全局变量的依赖。

## `global`

`global` 用于在函数内部声明变量来自全局作用域，从而可以修改全局变量：

```python
count = 0


def increment():
    global count
    count += 1


increment()
print(count)  # 1
```

> **注意**：只有在确实需要修改全局变量时才使用 `global`，更常见的做法是通过参数传入数据、使用返回值传出结果。

## `nonlocal`

`nonlocal` 用于在内层函数中引用并修改外层函数的局部变量，不能用于全局变量：

```python
def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1
        return count

    print(inner())  # 1
    print(inner())  # 2


outer()
```

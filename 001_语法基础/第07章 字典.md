# 认识字典

字典是一种可变映射，用于以键值对的形式存储数据。每个键必须唯一，值可以重复。

字典使用花括号 **{ }**，键和值之间使用冒号 **:** 分隔，键值对之间使用逗号 **,** 分隔。

语法格式：

```text
data = {key1: value1, key2: value2, key3: value3}
```

# 基本操作

## 创建字典

使用花括号 **{ }** 创建字典，也可以使用内置函数 `dict()` 创建字典。

```python
# 创建空字典
empty_dict = {}

print(empty_dict)
print("Length:", len(empty_dict))
print(type(empty_dict))
```

输出结果：

```
{}
Length: 0
<class 'dict'>
```

## 访问字典中的值

将键放入方括号中，可以访问对应的值：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

print("infos['name']：", infos["name"])
print("infos['age']：", infos["age"])
```

输出结果：

```
infos['name']： 张三
infos['age']： 18
```

使用方括号访问不存在的键会抛出 `KeyError`。如果不确定键是否存在，可以使用 `get()`：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

# print(infos["job"])  # KeyError: 'job'
print(infos.get("job"))  # None
```

## 修改字典

通过键可以添加新的键值对，也可以修改已有键对应的值：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

infos["name"] = "李四"  # 修改已有值
infos["city"] = "上海市浦东区"  # 添加新的键值对
print(infos)
```

输出结果：

```text
{'name': '李四', 'age': 18, 'address': '成都市高新区', 'city': '上海市浦东区'}
```

## 删除字典中的元素

可以使用 `del` 删除指定键值对，使用 `clear()` 清空字典：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

del infos["address"]  # 删除指定键值对
infos.clear()          # 清空字典
print(infos)
```

输出结果：

```
{}
```

使用 `del infos` 可以删除变量 `infos` 对字典的引用。

# 字典键的特性

1. 字典的键必须唯一。创建或更新字典时，如果键重复，后面的值会覆盖前面的值。
2. 键必须是可哈希对象，通常可以使用数字、字符串和只包含可哈希元素的元组；列表、字典和集合不能作为键。
3. 值可以是任意数据类型，包括列表、字典等可变对象。

# 字典常用函数和方法

## 常用内置函数

- [`len(data)`](https://docs.python.org/zh-cn/3/library/functions.html#len)：返回字典中键值对的数量
- [`str(data)`](https://docs.python.org/zh-cn/3/library/functions.html#func-str)：返回字典的字符串表示
- [`type(data)`](https://docs.python.org/zh-cn/3/library/functions.html#type)：返回对象的类型
- [`dict(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-dict)：使用可迭代对象创建字典

## 常用方法

- [`dict.clear()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.clear)：删除字典中的所有元素
- [`dict.copy()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.copy)：返回字典的浅拷贝
- [`dict.fromkeys(iterable, value=None)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.fromkeys)：使用可迭代对象中的元素创建新字典
- [`dict.get(key, default=None)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.get)：返回指定键的值；键不存在时返回 `default`
- [`key in data`](https://docs.python.org/zh-cn/3/library/stdtypes.html#mapping-types-dict)：判断键是否存在于字典中
- [`dict.items()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.items)：返回包含所有键值对的视图对象
- [`dict.keys()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.keys)：返回包含所有键的视图对象
- [`dict.setdefault(key, default=None)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.setdefault)：返回指定键的值；键不存在时添加该键并设置默认值
- [`dict.update(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.update)：使用另一个映射或可迭代对象更新字典
- [`dict.values()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.values)：返回包含所有值的视图对象
- [`dict.pop(key[, default])`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.pop)：删除并返回指定键的值
- [`dict.popitem()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.popitem)：删除并返回最后插入的键值对

> **注意**：`items()`、`keys()` 和 `values()` 返回的是动态视图对象，不是列表；大多数修改类方法会直接修改原字典并返回 `None`。

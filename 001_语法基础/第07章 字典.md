# 认识字典

字典（`dict`）是一种可变映射，用于存储键值对。键唯一，值可以重复；遍历时保留键的插入顺序。

字典使用花括号 **{ }**，键和值之间使用冒号 **:** 分隔，键值对之间使用逗号 **,** 分隔。

语法格式：

```text
data = {key1: value1, key2: value2, key3: value3}
```

# 基本操作

## 创建字典

使用花括号 `{}` 创建字典，也可以使用 [`dict()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict) 从映射、键值对序列或关键字参数创建字典。

```python
# 创建空字典
empty_dict = {}

print(empty_dict)
print("Length:", len(empty_dict))
print(type(empty_dict))

# 输出结果：
# {}
# Length: 0
# <class 'dict'>
```

```python
print(dict([("name", "张三"), ("age", 18)]))  # {'name': '张三', 'age': 18}
print(dict(name="张三", age=18))              # {'name': '张三', 'age': 18}
```

## 访问字典中的值

将键放入方括号中，可以访问对应的值：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

print("infos['name']：", infos["name"])
print("infos['age']：", infos["age"])

# 输出结果：
# infos['name']： 张三
# infos['age']： 18
```

使用方括号访问不存在的键会抛出 `KeyError`。如果不确定键是否存在，可以使用 `get()`：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

# print(infos["job"])  # KeyError: 'job'
print(infos.get("job"))  # None
print(infos.get("job", "未填写"))  # 未填写
```

`get()` 不会添加键；默认值只在键不存在时使用，已有值为 `None` 时仍返回 `None`。`key in data` 判断键是否存在，不检查值。

## 修改字典

通过键可以添加新的键值对，也可以修改已有键对应的值：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

infos["name"] = "李四"  # 修改已有值
infos["city"] = "上海市浦东区"  # 添加新的键值对
print(infos)

# 输出结果：
# {'name': '李四', 'age': 18, 'address': '成都市高新区', 'city': '上海市浦东区'}
```

## 删除字典中的元素

可以使用 `del` 删除指定键值对，使用 `clear()` 清空字典：

```python
infos = {"name": "张三", "age": 18, "address": "成都市高新区"}

del infos["address"]  # 删除指定键值对
infos.clear()          # 清空字典
print(infos)

# 输出结果：
# {}
```

`del infos[key]` 在键不存在时抛出 `KeyError`。需要取出值并删除时使用 `pop()`；允许键不存在时传入默认值。

## 遍历字典

直接遍历字典得到键，使用 `items()` 可以同时获取键和值：

```python
infos = {"name": "张三", "age": 18}

for key, value in infos.items():
    print(key, value)

# 输出结果：
# name 张三
# age 18
```

更新已有键的值不会改变它的位置；删除后重新插入会移动到末尾。遍历过程中增删键可能抛出 `RuntimeError`，需要删除时可遍历副本或通过推导式创建新字典。

# 字典键的特性

1. 字典的键必须唯一。创建或更新字典时，如果键重复，后面的值会覆盖前面的值。
2. 键必须是可哈希对象，通常可以使用数字、字符串和只包含可哈希元素的元组；列表、字典和集合不能作为键。
3. 值可以是任意数据类型，包括列表、字典等可变对象。

相等且哈希相同的键会视为同一个键，例如 `1`、`1.0` 和 `True`，不要用它们表示不同字段。

# 字典常用函数和方法

## 常用内置函数

- [`len(data)`](https://docs.python.org/zh-cn/3/library/functions.html#len)：返回字典中键值对的数量
- [`str(data)`](https://docs.python.org/zh-cn/3/library/functions.html#func-str)：返回字典的字符串表示
- [`type(data)`](https://docs.python.org/zh-cn/3/library/functions.html#type)：返回对象的类型
- [`dict(iterable)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict)：从映射或键值对可迭代对象创建字典

## 常用方法

- [`dict.clear()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.clear)：删除字典中的所有元素
- [`dict.copy()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.copy)：返回字典的浅拷贝
- [`dict.fromkeys(iterable, value=None)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.fromkeys)：以可迭代对象中的元素为键创建字典，所有键共享同一个 `value`
- [`dict.get(key, default=None)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.get)：返回指定键的值；键不存在时返回 `default`
- [`key in data`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict)：判断键是否存在于字典中
- [`dict.items()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.items)：返回包含所有键值对的视图对象
- [`dict.keys()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.keys)：返回包含所有键的视图对象
- [`dict.setdefault(key, default=None)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.setdefault)：返回指定键的值；键不存在时添加该键并设置默认值
- [`dict.update(other)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.update)：使用另一个映射或可迭代对象更新字典
- [`dict.values()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.values)：返回包含所有值的视图对象
- [`dict.pop(key, default)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.pop)：删除并返回指定键的值；`default` 可省略，键不存在且未给默认值时抛出 `KeyError`
- [`dict.popitem()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.popitem)：删除并返回最后插入的 `(key, value)`，空字典时抛出 `KeyError`

> **注意**：`items()`、`keys()` 和 `values()` 返回的是动态视图对象，不是列表；大多数修改类方法会直接修改原字典并返回 `None`。

## 视图与快照

动态视图会反映字典的后续变化；需要固定当前键列表时，使用 [`list(data)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list)：

```python
data = {"a": 1}
keys = data.keys()
snapshot = list(data)
data["b"] = 2

print(list(keys))  # ['a', 'b']
print(snapshot)    # ['a']
```

## 默认值与分组

`setdefault()` 在缺少键时写入默认值，并返回该键对应的值；已有键的值不会被替换：

```python
groups = {}
for city, name in [("成都", "张三"), ("成都", "李四")]:
    groups.setdefault(city, []).append(name)

print(groups)  # {'成都': ['张三', '李四']}
```

`dict.fromkeys(keys, [])` 会让所有键共享同一个列表。需要独立列表时使用字典推导式：

```python
shared = dict.fromkeys(["a", "b"], [])
shared["a"].append(1)
print(shared)  # {'a': [1], 'b': [1]}

independent = {key: [] for key in ["a", "b"]}
independent["a"].append(1)
print(independent)  # {'a': [1], 'b': []}
```

# 字典推导式与合并

字典推导式用于转换或筛选键值对：

```python
prices = {"apple": 5, "pear": 3}
result = {name: price * 2 for name, price in prices.items() if price >= 5}
print(result)  # {'apple': 10}
```

合并字典时，[`d | other`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict) 返回新字典，`d |= other` 原地更新；重复键取右侧的值。`{**d, **other}` 也可以创建合并后的新字典。

```python
defaults = {"theme": "light", "timeout": 30}
overrides = {"timeout": 10}

config = defaults | overrides
print(config)    # {'theme': 'light', 'timeout': 10}
print(defaults)  # {'theme': 'light', 'timeout': 30}
```

`copy()` 和合并操作都是浅拷贝，嵌套列表、字典等对象仍然共享，详见第09章。

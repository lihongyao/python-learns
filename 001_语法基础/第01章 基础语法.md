# 注释

```python
# 单行注释：从 # 开始，到当前物理行结束
name = "张三"  # 行尾注释
```

三引号字符串不是专门的“多行注释”。放在模块、函数或类的第一条语句位置时，它才是文档字符串（docstring）：

```python
"""模块说明。"""


def greet():
    """返回问候语。"""
    return "Hello"
```

Python 3 默认使用 UTF-8 解析源文件，通常不需要额外声明编码。

# 语句与缩进

- Python 使用换行结束一条逻辑语句，复合语句的代码块以冒号 `:` 开始。
- 缩进表示代码块，推荐统一使用 4 个空格；不要混用 Tab 和空格。
- 圆括号、方括号和花括号内可以跨行书写，优先使用这种隐式续行方式。

```python
total = (
    first_price
    + second_price
    - discount
)
```

# 输入与输出

## 输出

`print()` 默认将多个对象以空格分隔，并在末尾换行：

```python
print(1, 2, 3)
print(1, 2, 3, sep="*", end="!")  # 1*2*3!
```

- `sep`：多个对象之间的分隔符，默认是空格。
- `end`：输出末尾的字符串，默认是换行符 `"\n"`。

## 输入

`input(prompt)` 显示提示信息并读取一行输入，返回值始终是 `str`：

```python
name = input("请输入姓名：")
age = int(input("请输入年龄："))
print(f"{name} 今年 {age} 岁")
```

输入可能无法转换为目标类型，实际程序应根据需要处理 `ValueError`（异常处理见后续章节）。

# 变量与赋值

Python 变量本质上是绑定到对象的名称，不需要提前声明类型。赋值语句会把右侧对象绑定到左侧名称：

```python
value = 1
value = "文本"  # 同一名称可以先后绑定不同类型的对象
```

赋值不会自动复制对象，多个名称可能指向同一个对象：

```python
items = [1, 2]
alias = items
alias.append(3)
print(items)  # [1, 2, 3]
```

需要复制时，根据对象结构选择切片、`.copy()` 或 `copy.deepcopy()`。

## 常用赋值形式

```python
# 同时赋值
width, height = 800, 600

# 交换两个变量的值
width, height = height, width

# 可迭代对象解包
first, *middle, last = [1, 2, 3, 4] # first = 1, middle = [2, 3], last = 4
```

赋值右侧会先整体求值，再完成绑定，因此交换变量不需要临时变量。

## `None`

`None` 表示“没有值”或“缺省值”，类型是 `NoneType`。判断是否为 `None` 时使用 `is`：

```python
result = None
if result is None:
    print("没有结果")
```

# 标识符

标识符用于命名变量、函数、类、模块等对象。

## 强制规则

1. 可以使用 Unicode 字母、数字和下划线 `_`，但不能以数字开头。
2. 不能使用关键字，例如 `if`、`for`、`class`、`return`。
3. 区分大小写，`name` 和 `Name` 是两个不同的名称。

## 命名规范

- 变量和函数：`snake_case`，如 `user_age`。
- 类：`CapWords`，如 `UserProfile`。
- 常量：`UPPER_CASE`，如 `MAX_RETRY`。
- 模块和包：短小的 `snake_case` 名称。
- 名称应表达含义，避免使用 `l`、`O`、`I` 等容易混淆的单字符名称。

关键字列表可通过 `keyword` 模块查看：

```python
import keyword

print(keyword.kwlist)
```

# 数字

## 常用数字类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `int` | 任意精度整数 | `42`、`1_000_000` |
| `float` | 通常为双精度的浮点数 | `3.14`、`1.5e3` |
| `bool` | `True` 或 `False` | `True`、`False` |

常用整数还可以使用二进制、八进制和十六进制字面量：

```python
decimal = 42
binary = 0b101010
octal = 0o52
hexadecimal = 0x2A
```

`bool` 是 `int` 的子类：`True` 和 `False` 在数值运算中分别按 `1` 和 `0` 处理，但业务代码中不要依赖这种隐式转换。

## 浮点数注意事项

浮点数采用二进制近似表示，不适合直接用 `==` 判断需要精确的小数结果：

```python
print(0.1 + 0.2 == 0.3)  # False
```

金额等需要十进制精确计算的场景，使用 `decimal.Decimal`，不要用 `float` 直接累计。

# 字符串

字符串类型是 `str`，由 Unicode 字符组成。单引号和双引号没有语义差异，选择一种并在项目中保持一致：

```python
single = 'Python'
double = "Python"
```

字符串包含引号时，可以改用另一种引号或使用转义：

```python
message = "It's Python"
quoted = '他说："你好"'
```

三引号字符串可以跨越多行，也常用于文档字符串：

```python
text = """第一行
第二行"""
```

字符串是不可变对象，不能通过下标直接修改其中的字符。字符串的索引、切片和常用方法见“字符串”章节。

# 格式化输出

## f-字符串（推荐）

在字符串前加 `f` 或 `F`，在 `{}` 中写入表达式；冒号后的内容是格式说明符：

```python
name = "张三"
age = 18
score = 95.236

print(f"姓名：{name}，年龄：{age}")
print(f"成绩：{score:.2f}")        # 保留 2 位小数
print(f"学号：{7:03d}")            # 宽度 3，不足时补 0
print(f"{name=}, {age=}")         # 调试时同时显示名称和值
```

常用转换标志：

- `!s`：使用 `str()` 转换。
- `!r`：使用 `repr()` 转换，适合调试。

```python
value = "hello"
print(f"{value!r}")  # 'hello'
```

## 其他格式化方式

`str.format()` 和 `%` 格式化仍可读懂旧代码，但新代码通常优先使用 f-字符串：

```python
"{} + {} = {}".format(1, 2, 3)
"%s + %s = %s" % (1, 2, 3)
```

# 运算符

## 算术运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `+` | 加法，也可用于字符串或序列拼接 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法，也可重复序列 | `a * b` |
| `/` | 真除法，结果通常为 `float` | `7 / 2 == 3.5` |
| `//` | 向下取整除法 | `7 // 2 == 3` |
| `%` | 取余 | `7 % 2 == 1` |
| `**` | 幂运算 | `2 ** 3 == 8` |

`//` 是向负无穷取整，不是简单截断：`-7 // 2 == -4`。

运算优先级容易造成误读时，直接使用括号。常见优先级为：幂运算 `**` > 乘除、整除、取余 > 加减。

## 赋值运算符

| 运算符 | 等价形式 |
| --- | --- |
| `=` | `a = b` |
| `+=` | `a = a + b` |
| `-=` | `a = a - b` |
| `*=` | `a = a * b` |
| `/=` | `a = a / b` |
| `//=` | `a = a // b` |
| `%=` | `a = a % b` |
| `**=` | `a = a ** b` |

复合赋值会先读取左侧当前值，因此左侧名称必须已经存在。对可变对象使用 `+=` 时，可能会原地修改对象；不要简单地把它与普通赋值视为完全相同。

## 比较与身份运算符

| 运算符 | 含义 |
| --- | --- |
| `==`、`!=` | 值相等、不相等 |
| `<`、`<=`、`>`、`>=` | 大小比较 |
| `is`、`is not` | 是否为同一个对象 |

`==` 比较值，`is` 比较对象身份。业务值比较使用 `==`；判断单例对象（最常见是 `None`）使用 `is`：

```python
if value is None:
    ...
```

比较支持链式写法：

```python
if 18 <= age < 60:
    ...
```

## 逻辑运算符

| 运算符 | 规则 |
| --- | --- |
| `not x` | 返回 `True` 或 `False`，反转真假值 |
| `x and y` | `x` 为假时返回 `x`，否则返回 `y` |
| `x or y` | `x` 为真时返回 `x`，否则返回 `y` |

`and` 和 `or` 具有短路行为，后面的表达式可能不会执行：

```python
user = get_user()
name = user and user.name  # user 为假时，不访问 user.name
```

条件判断使用“真值测试”。以下对象通常为假：`False`、`None`、数值零、空字符串以及空容器；其他对象通常为真。需要显式转换时使用 `bool(value)`。

## 成员运算符

`in` 和 `not in` 判断成员关系。对字典使用 `in` 时检查的是键：

```python
allowed = {"read", "write"}
if "read" in allowed:
    print("允许读取")

config = {"debug": True}
print("debug" in config)  # True
```

# 转义字符与原始字符串

常用转义序列如下：

| 转义序列 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 水平制表符 |
| `\\` | 反斜杠本身 |
| `\'` | 单引号 |
| `\"` | 双引号 |

```python
print("第一行\n第二行")
print("姓名\t年龄")
```

原始字符串前加 `r`，通常用于 Windows 路径和正则表达式，反斜杠不会按普通转义序列处理：

```python
path = r"C:\Users\example\Documents"
```

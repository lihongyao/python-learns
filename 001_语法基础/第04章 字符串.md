# 概述

字符串是 Python 中常用的数据类型，由 Unicode 字符组成。字符串是不可变的序列，修改字符串时会创建新的字符串对象。

可以使用单引号、双引号或三引号创建字符串：

```python
s1 = "Python"
s2 = 'Python'
s3 = """第一行
第二行"""
```

单引号和双引号没有语义差异，项目中保持风格一致即可。字符串前还可以使用常见前缀：

- `r`：原始字符串，反斜杠通常不作为转义符。
- `f`：格式化字符串，支持在字符串中嵌入表达式。
- `b`：字节串，类型是 `bytes`，不能与 `str` 直接拼接。

# 字符串编码

字符串和字节串是不同的数据类型：

- 字符串（`str`）表示文本。
- 字节串（`bytes`）表示二进制数据，常用于文件、网络和编码转换。

Unicode 是字符与码点的统一标准，不是具体的字节编码；UTF-8、GBK 等才是编码方式。

## 编码与解码

- [str.encode(encoding="utf-8", errors="strict")](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.encode)：将字符串编码为 `bytes`。
- [bytes.decode(encoding="utf-8", errors="strict")](https://docs.python.org/zh-cn/3/library/stdtypes.html#bytes.decode)：将 `bytes` 解码为字符串。

默认编码通常是 UTF-8，编码和解码必须使用相互匹配的编码方式：

```python
text = "王者荣耀"

encoded = text.encode("utf-8")
print(encoded, type(encoded))

decoded = encoded.decode("utf-8")
print(decoded, type(decoded))

# 输出结果：
# b'\xe7\x8e\x8b\xe8\x80\x85\xe8\x8d\xa3\xe8\x80\x80' <class 'bytes'>
# 王者荣耀 <class 'str'>
```

如果编码方式不匹配，可能抛出 `UnicodeDecodeError` 或 `UnicodeEncodeError`。`errors` 常见取值包括 `"strict"`、`"ignore"` 和 `"replace"`；除非明确知道后果，否则使用默认的 `"strict"`。

# 字符串运算符

| 运算符 | 描述 | 示例 |
| :--- | :--- | :--- |
| `+` | 字符串拼接 | `"Hello" + "Python"` → `"HelloPython"` |
| `*` | 重复字符串 | `"Hi" * 3` → `"HiHiHi"` |
| `[]` | 通过索引获取字符 | `"Hello"[1]` → `'e'` |
| `[:]` | 获取切片 | `"Hello"[1:4]` → `"ell"` |
| `in` | 判断是否包含子字符串 | `"Py" in "Python"` → `True` |
| `not in` | 判断是否不包含子字符串 | `"Java" not in "Python"` → `True` |

相邻的字符串字面量会自动拼接，变量或表达式不能依赖这种写法：

```python
message = (
    "第一部分"
    "第二部分"
)
print(message)  # 第一部分第二部分
```

大量拼接字符串时，优先使用 [str.join()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.join)，不要在循环中反复使用 `+`。

## `+` 与 `*`

```python
print("1" + "1")
print("0" * 3)

first_name = "张"
last_name = "三"
print(first_name + last_name)

# 输出结果：
# 11
# 000
# 张三
```

## `in` 与 `not in`

```python
poem = "晓看红湿处,花重锦官城"

print("锦官城" in poem)       # True
print("凤凰城" in poem)       # False
print("锦官城" not in poem)   # False
print("凤凰城" not in poem)   # True
```

# 索引

字符串索引从 `0` 开始，负数索引从末尾开始。索引超出范围会抛出 `IndexError`：

```python
letters = "ABCD"

print(letters[0])    # A
print(letters[-1])   # D
print(letters[-2])   # C
# print(letters[4])  # IndexError: string index out of range
```

字符串中的单个字符没有独立类型，取出的结果仍然是长度为 1 的 `str`。

# 切片

切片语法：

```text
seq[start:stop:step]
```

- `start`：起始索引，包含，默认从开头开始。
- `stop`：结束索引，不包含，默认到末尾结束。
- `step`：步长，默认是 `1`，不能为 `0`；负数表示反向切片。

```python
letters = "ABCDEFGHIJKLMN"

print(letters[3:7])        # DEFG
print(letters[:5])         # ABCDE
print(letters[3:])         # DEFGHIJKLMN
print(letters[:])          # ABCDEFGHIJKLMN
print(letters[::2])        # ACEGIKM
print(letters[::-1])       # NMLKJIHGFEDCBA
print(letters[1:10:2])     # BDFHJ
print(letters[-1:-11:-2])  # NLJHF
```

切片的索引超出范围不会抛出 `IndexError`，而是按实际边界处理；步长为 `0` 时会抛出 `ValueError`。

# 字符串常用 API

字符串方法不会修改原字符串，通常会返回新字符串、布尔值或其他结果。

## 查找与判断

- [len(s)](https://docs.python.org/zh-cn/3/library/functions.html#len)：返回字符串长度。✔️
- [str.count(sub, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.count)：统计子字符串非重叠出现的次数。✔️
- [str.find(sub, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.find)：查找子字符串，未找到返回 `-1`。✔️
- [str.rfind(sub, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.rfind)：从右侧查找，未找到返回 `-1`。
- [str.index(sub, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.index)：功能类似 `find()`，未找到时抛出 `ValueError`。✔️
- [str.rindex(sub, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.rindex)：从右侧查找，未找到时抛出 `ValueError`。
- [str.startswith(prefix, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.startswith)：判断是否以指定前缀开头。✔️
- [str.endswith(suffix, start, end)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.endswith)：判断是否以指定后缀结尾。✔️

`find()` 适合“不确定是否存在”的查找；`index()` 适合“必须存在，否则立即报错”的场景。

`startswith()` 和 `endswith()` 支持传入元组，一次判断多个前缀或后缀：

```python
filename = "report.csv"
print(filename.endswith((".csv", ".xlsx")))  # True
```

## 分割与拼接

- [str.split(sep=None, maxsplit=-1)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.split)：按分隔符分割字符串。✔️
- [str.rsplit(sep=None, maxsplit=-1)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.rsplit)：从右侧开始分割。
- [str.splitlines(keepends=False)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.splitlines)：按行边界分割字符串。
- [str.join(iterable)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.join)：使用当前字符串作为分隔符连接字符串。✔️
- [str.partition(sep)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.partition)：按第一次出现的分隔符拆成三部分。
- [str.rpartition(sep)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.rpartition)：按最后一次出现的分隔符拆成三部分。

省略 `split()` 的 `sep` 时，会按连续空白分割，并忽略两端空白；显式传入 `sep` 时，连续分隔符会产生空字符串：

```python
text = "  Python   FastAPI  "

print(text.split())        # ['Python', 'FastAPI']
print("a,,b".split(","))   # ['a', '', 'b']
```

`join()` 的可迭代对象必须包含字符串，不能直接连接整数等其他类型：

```python
words = ["Python", "is", "fun"]
print(" ".join(words))  # Python is fun

numbers = [1, 2, 3]
print(",".join(map(str, numbers)))  # 1,2,3
```

`partition()` 无论是否找到分隔符，都会返回长度为 `3` 的元组；未找到时结果为 `(原字符串, "", "")`。

## 替换与去除

- [str.replace(old, new, count=-1)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.replace)：替换子字符串，`count` 指定最多替换次数。✔️
- [str.strip(chars=None)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.strip)：删除两端空白或指定字符集合。✔️
- [str.lstrip(chars=None)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.lstrip)：删除左侧空白或指定字符集合。
- [str.rstrip(chars=None)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.rstrip)：删除右侧空白或指定字符集合。
- [str.removeprefix(prefix)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.removeprefix)：如果存在指定前缀，则删除一次。
- [str.removesuffix(suffix)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.removesuffix)：如果存在指定后缀，则删除一次。

`strip(chars)` 删除的是“字符集合”，不是一个完整子字符串：

```python
text = "  ---Python---  "

print(text.strip())        # ---Python---
print(text.strip(" -"))    # Python
print("filename.txt".removesuffix(".txt"))   # filename
print("prefix_data".removeprefix("prefix_")) # data
```

## 大小写转换

- [str.lower()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.lower)：转换为小写。✔️
- [str.upper()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.upper)：转换为大写。✔️
- [str.casefold()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.casefold)：更彻底地转换为适合无视大小写比较的形式。
- [str.capitalize()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.capitalize)：首字符大写，其余字符小写。
- [str.title()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.title)：将单词首字符转换为大写。

不区分大小写比较时，优先考虑 `casefold()` 而不是 `lower()`：

```python
print("Python".casefold() == "python".casefold())  # True
```

## 字符串验证

- [str.isalnum()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isalnum)：是否只包含字母和数字，且至少有一个字符。
- [str.isalpha()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isalpha)：是否只包含字母字符，且至少有一个字符。
- [str.isdecimal()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isdecimal)：是否只包含十进制数字字符。
- [str.isdigit()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isdigit)：是否只包含数字字符。
- [str.isnumeric()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isnumeric)：数字范围比 `isdigit()` 更广。
- [str.isspace()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isspace)：是否只包含空白字符，且至少有一个字符。
- [str.islower()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.islower)：是否包含区分大小写的字符且均为小写。
- [str.isupper()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isupper)：是否包含区分大小写的字符且均为大写。
- [str.isascii()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isascii)：是否只包含 ASCII 字符。
- [str.isprintable()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.isprintable)：是否所有字符都可打印。

`isdecimal()`、`isdigit()` 和 `isnumeric()` 的判断范围不同；处理用户输入时，应根据业务规则选择，不要只凭方法名猜测。

## 格式化与填充

- [str.format()](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.format)：使用格式字段生成新字符串。
- [str.center(width, fillchar=" ")](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.center)：返回居中填充后的字符串。
- [str.ljust(width, fillchar=" ")](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.ljust)：返回左对齐字符串。
- [str.rjust(width, fillchar=" ")](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.rjust)：返回右对齐字符串。
- [str.zfill(width)](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.zfill)：在左侧填充 `0`，保留正负号位置。

f-字符串是新代码的首选；`str.format()` 主要用于旧代码或格式模板：

```python
name = "张三"
score = 95

print("{}: {}".format(name, score))  # 张三: 95
print(f"{name}: {score}")            # 张三: 95
```

# 异常处理

程序运行过程中可能会发生异常。异常会中断当前代码的执行，如果没有被处理，程序会输出错误信息并终止。

语法错误（`SyntaxError`）通常在程序执行前被发现，不能通过同一代码块中的 `try` 捕获；异常处理主要用于处理运行期间发生的错误。

# `try...except`

Python 使用 `try...except` 语句捕获和处理异常，`else` 和 `finally` 块是可选的。

语法格式：

```text
try:
    可能引发异常的代码
except 异常类型 as exc:
    异常处理代码
else:
    没有发生异常时执行的代码
finally:
    无论是否发生异常都会执行的代码
```

示例：

```python
try:
    number = int("abc")
except ValueError:
    print("转换失败")
```

> **注意**：尽量捕获明确的异常类型，避免直接使用裸 `except`，否则可能会隐藏真正的程序错误。

# 异常触发流程

当异常发生时，Python 会停止当前代码，沿调用栈向上寻找匹配的异常处理器。如果一直没有找到处理器，就会由默认处理器输出 `Traceback`。

```python
def func1():
    raise ValueError("Deep error")


def func2():
    func1()


def main():
    try:
        func2()
    except ValueError as exc:
        print(f"Caught exception: {exc}")


main()  # Caught exception: Deep error
```

# 常见异常类型

- `SyntaxError`：语法错误，代码不符合 Python 语法
- `TypeError`：类型错误，例如将字符串和整数相加
- `ValueError`：值错误，例如将 `"abc"` 转换为整数
- `NameError`：名称错误，使用了未定义的变量
- `IndexError`：索引错误，序列索引超出范围
- `KeyError`：键错误，字典中不存在指定的键
- `FileNotFoundError`：文件未找到
- `OSError`：操作系统或输入输出相关错误
- `ZeroDivisionError`：除零错误
- `AttributeError`：属性错误，访问对象不存在的属性或方法
- `Exception`：大多数常规异常的基类

> **提示**：Python 3 中的 `IOError` 是 `OSError` 的别名，通常直接使用 `OSError`。

# 捕获指定异常

可以在 `except` 后指定一个或多个异常类型：

```python
try:
    number = int("abc")
except ValueError:
    print("传入的值有问题")


try:
    print(undefined_name)
except (NameError, ValueError):
    print("捕获到名称错误或值错误")
```

使用 `as` 可以将异常对象保存到变量中，读取具体的错误信息：

```python
try:
    print(undefined_name)
except NameError as exc:
    print(f"异常信息：{exc}")
```

`Exception` 可以捕获大多数常规异常，但不建议把它作为日常代码中的首选类型：

```python
try:
    number = int("abc")
except Exception as exc:
    print(f"异常信息：{exc}")
```

# `else` 和 `finally`

## `else`

`else` 只在 `try` 代码块没有发生异常时执行，适合放置依赖成功结果的后续代码：

```python
try:
    number = int("42")
except ValueError:
    print("转换失败")
else:
    print("转换成功：", number)
```

## `finally`

`finally` 无论是否发生异常都会执行，常用于关闭文件、释放锁等清理工作：

```python
print("开始操作")

try:
    print("执行操作")
except Exception as exc:
    print(f"操作失败：{exc}")
finally:
    print("执行清理")
```

执行流程可以概括为：

| 情况           | 执行顺序                         |
| :------------- | :------------------------------- |
| 未发生异常     | `try` → `else` → `finally`        |
| 异常被捕获     | `try` → `except` → `finally`     |
| 异常未被捕获   | `try` → `finally` → 继续抛出异常 |

`try` 也可以单独与 `finally` 使用：

```python
try:
    print("执行操作")
finally:
    print("执行清理")
```

# 主动抛出异常

使用 `raise` 可以在满足特定条件时主动抛出异常：

```text
raise 异常类型("异常描述信息")
```

示例：

```python
def validate_age(age):
    if age < 0:
        raise ValueError("年龄不能为负数")
    return age


try:
    print(validate_age(-1))
except ValueError as exc:
    print(f"校验失败：{exc}")
```

# 自定义异常

对于与业务规则相关的错误，可以定义继承自 `Exception` 或其子类的异常：

```python
class PasswordTooShortError(ValueError):
    pass


def validate_password(password):
    if len(password) < 8:
        raise PasswordTooShortError("密码长度不能少于 8 位")
    return password


try:
    validate_password("123456")
except PasswordTooShortError as exc:
    print(f"校验失败：{exc}")
```

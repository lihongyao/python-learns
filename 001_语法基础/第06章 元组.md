# 认识元组

Python 的元组与列表类似，是一种有序、不可变的序列。元组创建后，不能修改、添加或删除其中的元素。

元组通常使用小括号 **( )** 包裹，真正区分元组的是逗号；列表使用方括号 **[ ]**。

元组创建很简单，只需要在括号中添加元素，并使用逗号分隔即可。

语法格式：

```text
变量名 = (元素 1, 元素 2, 元素 3, ...)
```

注意事项：

1. 元组中的元素按顺序放置在小括号内，各个元素之间使用逗号分隔。
2. 元组中的元素可以是不同类型，也可以嵌套列表、元组、字典、集合等对象。
3. 定义只包含一个元素的元组时，必须在元素末尾加上逗号；否则 Python 会将其视为该元素本身，而不是元组。
4. 元组本身不可变，但其中的列表等可变对象仍然可以修改。

代码示例：

```python
tuple1 = (1, 2, 3)
print(tuple1, type(tuple1))  # (1, 2, 3) <class 'tuple'>

tuple2 = (False, 3.14, "hello", [1, 2], (1, 2, 3))
print(tuple2, type(tuple2))  # (False, 3.14, 'hello', [1, 2], (1, 2, 3)) <class 'tuple'>

not_tuple = (1)
print(not_tuple, type(not_tuple))  # 1 <class 'int'>

one_tuple = (1,)
print(one_tuple, type(one_tuple))  # (1,) <class 'tuple'>
```

# 基本使用

## 访问元组元素

可以通过索引（下标）访问元组中的元素。索引从 **0** 开始，负数索引从 **-1** 开始。

代码示例：

```python
items = ("A", "B", "C", "D")

print(items[0])   # A
print(items[1])   # B
print(items[-1])  # D
print(items[-2])  # C

# print(items[4])   # IndexError: tuple index out of range
# print(items[-5])  # IndexError: tuple index out of range
```

## 元组切片

和列表一样，元组也支持切片操作，可以获取元组的一部分。切片范围遵循 **左闭右开** 原则。

语法格式：

```text
序列[start:stop:step]
```

代码示例：

```python
items = ("A", "B", "C", "D")

print(items[1:3])       # ('B', 'C')
print(items[0:4:2])     # ('A', 'C')
print(items[-1:-4:-2])  # ('D', 'B')
```

## 遍历元组

元组是可迭代对象，可以使用 `for` 循环遍历其中的每个元素。

代码示例：

```python
items = ("A", "B", "C", "D")

for item in items:
    print(item)
```

输出结果：

```
A
B
C
D
```

# 元组常见操作

- [`len(items)`](https://docs.python.org/zh-cn/3/library/functions.html#len)：返回元组中元素的个数
- [`items.count(value)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#tuple.count)：统计某个值在元组中出现的次数
- [`items.index(value)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#tuple.index)：返回某个值第一次出现的索引，找不到时抛出 `ValueError`
- `value in items`：检查某个值是否存在于元组中
- `items1 + items2`：合并两个元组，返回新元组
- `items * n`：将元组重复 `n` 次，返回新元组
- [`max(items)`](https://docs.python.org/zh-cn/3/library/functions.html#max)：返回元组中的最大值，元素必须可以比较
- [`min(items)`](https://docs.python.org/zh-cn/3/library/functions.html#min)：返回元组中的最小值，元素必须可以比较
- [`tuple(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-tuple)：使用可迭代对象创建元组
- `for item in items:`：遍历元组中的元素
- [`sorted(items)`](https://docs.python.org/zh-cn/3/library/functions.html#sorted)：返回排序后的列表，元组本身不会改变

> **注意**：元组不可变，因此没有 `append`、`remove` 等修改类方法，常用方法只有 `count` 和 `index`。

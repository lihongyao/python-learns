# 类型转换

类型转换会得到目标类型的对象，不会原地改变原对象的类型。数值、文本与容器之间需要显式转换；容器转换也不会自动递归转换内部元素。

## 数值类型转换

- [`int(x)`](https://docs.python.org/zh-cn/3/library/functions.html#int)：将 `x` 转换为整数，从浮点数转换时向 0 截断
- [`int(x, base)`](https://docs.python.org/zh-cn/3/library/functions.html#int)：将字符串 `x` 按 `base` 进制转换为整数
- [`float(x)`](https://docs.python.org/zh-cn/3/library/functions.html#float)：将 `x` 转换为浮点数

```python
print(int(-3.9))       # -3
print(int("101", 2))   # 5
print(int("0xff", 0))  # 255：根据前缀识别进制
print(float("3.14"))   # 3.14
# int("3.14")  # ValueError：小数字符串不能直接转换为整数
```

类型转换与舍入不同，`int()` 不会四舍五入；如果业务允许先解析小数再截断，可使用 `int(float(text))`。

## 布尔类型转换

- [`bool(x)`](https://docs.python.org/zh-cn/3/library/functions.html#bool)：将 `x` 转换为布尔值；`None`、`False`、数字 `0`、空字符串和空容器等通常为 `False`

非空字符串的真值为 `True`，不会按文本内容解析：

```python
print(bool(""))       # False
print(bool("False"))  # True
print(bool("0"))      # True
```

## 字符串转换与处理

- [`str(x)`](https://docs.python.org/zh-cn/3/library/functions.html#func-str)：将 `x` 转换为适合阅读的字符串
- [`repr(x)`](https://docs.python.org/zh-cn/3/library/functions.html#repr)：返回对象的可打印表示，常用于调试
- [`json.loads(s)`](https://docs.python.org/zh-cn/3/library/json.html#json.loads)：解析 JSON 文本，返回对应的字典、列表等 Python 对象

`str()` 适合展示，`repr()` 适合查看调试表示；它们都不等同于 JSON 序列化：

```python
print(str("Python"))   # Python
print(repr("Python"))  # 'Python'

import json

data = json.loads('{"enabled": true, "count": 3}')
print(data)  # {'enabled': True, 'count': 3}
```

[`eval()`](https://docs.python.org/zh-cn/3/library/functions.html#eval) 会执行 Python 表达式，不用于普通数据转换；不要将外部输入直接传给它。

## 序列与集合转换

- [`list(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-list)：将可迭代对象转换为列表
- [`tuple(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-tuple)：将可迭代对象转换为元组
- [`set(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-set)：将可迭代对象转换为可变集合
- [`frozenset(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-frozenset)：将可迭代对象转换为不可变集合

```python
print(list("ABC"))            # ['A', 'B', 'C']
print(tuple([1, 2]))           # (1, 2)
print(sorted(set([3, 1, 3])))  # [1, 3]：集合去重，排序后便于查看
print(list("123"))            # ['1', '2', '3']：元素仍为字符串
print([int(x) for x in "123"]) # [1, 2, 3]：逐个转换元素
```

这里的 [`sorted()`](https://docs.python.org/zh-cn/3/library/functions.html#sorted) 用于将集合元素排序为列表，便于查看。

集合转换会去重且不保留原排列顺序；转换后的新容器仍可能与原对象共享内部元素。

## 字典转换

- [`dict(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-dict)：使用映射或键值对可迭代对象创建字典

转换字典时需要区分键、值和键值对：

```python
data = {"name": "张三", "age": 18}
print(list(data))          # ['name', 'age']
print(list(data.values())) # ['张三', 18]
print(list(data.items()))  # [('name', '张三'), ('age', 18)]

pairs = [("name", "张三"), ("age", 18)]
print(dict(pairs))         # {'name': '张三', 'age': 18}
```

这里用到的 [`dict.values()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.values) 返回值视图，[`dict.items()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#dict.items) 返回键值对视图。

## 字符与编码转换

- [`chr(x)`](https://docs.python.org/zh-cn/3/library/functions.html#chr)：将 Unicode 码点 `x` 转换为字符
- [`ord(x)`](https://docs.python.org/zh-cn/3/library/functions.html#ord)：将单个字符 `x` 转换为 Unicode 码点

码点转换与字节编码不同：[`str.encode()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#str.encode) 将文本编码为字节，[`bytes.decode()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#bytes.decode) 将字节解码为文本，详见第04章。

## 进制转换

- [`bin(x)`](https://docs.python.org/zh-cn/3/library/functions.html#bin)：将整数 `x` 转换为二进制字符串
- [`oct(x)`](https://docs.python.org/zh-cn/3/library/functions.html#oct)：将整数 `x` 转换为八进制字符串
- [`hex(x)`](https://docs.python.org/zh-cn/3/library/functions.html#hex)：将整数 `x` 转换为十六进制字符串

> **提示**：转换失败时可能抛出 `ValueError` 或 `TypeError`，例如将不合法的数字文本转换为整数。

## 类型判断

- [`type(obj)`](https://docs.python.org/zh-cn/3/library/functions.html#type)：返回对象的实际类型
- [`isinstance(obj, classinfo)`](https://docs.python.org/zh-cn/3/library/functions.html#isinstance)：判断对象是否属于指定类型或其子类；日常类型判断通常优先使用

```python
print(type(1) is int)               # True
print(isinstance(1, (int, float)))   # True
print(isinstance(True, int))        # True：bool 是 int 的子类
```

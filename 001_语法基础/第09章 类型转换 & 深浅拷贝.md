# 类型转换

类型转换是将对象转换为另一种数据类型的过程。Python 提供了许多内置函数来完成常见的类型转换。

## 数值类型转换

- [`int(x)`](https://docs.python.org/zh-cn/3/library/functions.html#int)：将 `x` 转换为整数，从浮点数转换时会截去小数部分
- [`int(x, base)`](https://docs.python.org/zh-cn/3/library/functions.html#int)：将字符串 `x` 按 `base` 进制转换为整数
- [`float(x)`](https://docs.python.org/zh-cn/3/library/functions.html#float)：将 `x` 转换为浮点数
- [`complex(real, imag)`](https://docs.python.org/zh-cn/3/library/functions.html#complex)：使用 `real` 和 `imag` 分别作为实部和虚部创建复数
- [`complex(x)`](https://docs.python.org/zh-cn/3/library/functions.html#complex)：将字符串或数字转换为复数

## 布尔类型转换

- [`bool(x)`](https://docs.python.org/zh-cn/3/library/functions.html#bool)：将 `x` 转换为布尔值；`None`、`False`、数字 `0`、空字符串和空容器等通常为 `False`

## 字符串转换与处理

- [`str(x)`](https://docs.python.org/zh-cn/3/library/functions.html#func-str)：将 `x` 转换为适合阅读的字符串
- [`repr(x)`](https://docs.python.org/zh-cn/3/library/functions.html#repr)：返回对象的可打印表示，常用于调试
- [`eval(expression)`](https://docs.python.org/zh-cn/3/library/functions.html#eval)：执行字符串形式的 Python 表达式并返回结果

> **注意**：不要对不可信的字符串使用 `eval()`，因为它可能执行任意 Python 代码。

## 序列与集合转换

- [`list(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-list)：将可迭代对象转换为列表
- [`tuple(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-tuple)：将可迭代对象转换为元组
- [`set(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-set)：将可迭代对象转换为可变集合
- [`frozenset(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-frozenset)：将可迭代对象转换为不可变集合

## 字典转换

- [`dict(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-dict)：使用映射或键值对可迭代对象创建字典

## 字符与编码转换

- [`chr(x)`](https://docs.python.org/zh-cn/3/library/functions.html#chr)：将 Unicode 码点 `x` 转换为字符
- [`ord(x)`](https://docs.python.org/zh-cn/3/library/functions.html#ord)：将单个字符 `x` 转换为 Unicode 码点

## 进制转换

- [`bin(x)`](https://docs.python.org/zh-cn/3/library/functions.html#bin)：将整数 `x` 转换为二进制字符串
- [`oct(x)`](https://docs.python.org/zh-cn/3/library/functions.html#oct)：将整数 `x` 转换为八进制字符串
- [`hex(x)`](https://docs.python.org/zh-cn/3/library/functions.html#hex)：将整数 `x` 转换为十六进制字符串

> **提示**：转换失败时可能抛出 `ValueError` 或 `TypeError`，例如将不合法的数字文本转换为整数。

# 深浅拷贝

变量赋值不会复制对象，只会让新的变量引用已有对象。通过一个变量修改对象时，其他引用同一对象的变量也会看到修改结果。

## 直接赋值

```python
original = {"name": "张三", "age": 18}
alias = original

alias["name"] = "李四"
print(original)       # {'name': '李四', 'age': 18}
print(original is alias)  # True
```

## 浅拷贝和深拷贝

Python 的 `copy` 模块提供了两种常用的拷贝方法：

- [`copy.copy(obj)`](https://docs.python.org/zh-cn/3/library/copy.html#copy.copy)：创建对象的浅拷贝，只复制最外层对象
- [`copy.deepcopy(obj)`](https://docs.python.org/zh-cn/3/library/copy.html#copy.deepcopy)：递归复制对象及其内部对象

```python
import copy

original = [1, [2, 3]]
shallow = copy.copy(original)
deep = copy.deepcopy(original)

shallow[1].append(4)
deep[1].append(5)

print(original)  # [1, [2, 3, 4]]
print(shallow)   # [1, [2, 3, 4]]
print(deep)      # [1, [2, 3, 5]]
```

以嵌套列表为例：

| 操作                  | 外层列表 | 嵌套列表 |
| :-------------------- | :------: | :------: |
| `alias = original`    |   共享   |   共享   |
| `copy.copy(original)` |   新对象 |   共享   |
| `copy.deepcopy(original)` | 新对象 | 新对象 |

## 浅拷贝

浅拷贝会创建新的外层对象，但内部嵌套的可变对象仍与原对象共享。因此，修改嵌套列表或字典时，原对象也可能受到影响。

## 深拷贝

深拷贝会递归复制对象及其内部对象。修改深拷贝结果中的嵌套可变对象，通常不会影响原对象。

# 可变类型与不可变类型

对象的可变性取决于创建后能否直接修改其内容。

## 可变类型

可变对象支持原地修改，修改前后通常仍是同一个对象。

- 列表（`list`）
- 字典（`dict`）
- 集合（`set`）
- 字节数组（`bytearray`）

## 不可变类型

不可变对象不能直接修改。需要改变值时，通常会创建新对象或让变量指向其他对象。

- 数字类型：整数（`int`）、浮点数（`float`）、复数（`complex`）、布尔值（`bool`）
- 字符串（`str`）
- 元组（`tuple`）
- 冻结集合（`frozenset`）
- 字节串（`bytes`）

## 核心区别

- 可变对象适合需要频繁修改的数据；直接赋值会共享同一个对象。
- 不可变对象不能原地修改，重新赋值只会让变量指向新对象。
- 很多不可变对象可以作为字典键或集合元素，但包含不可哈希元素的元组除外。

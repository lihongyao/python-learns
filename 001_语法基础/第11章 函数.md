# 函数

函数用于封装一段可复用的逻辑。函数定义时不会执行函数体，调用时才会执行。

# 定义和调用函数

## 定义函数

使用 `def` 定义函数，函数体必须缩进。函数名和参数名遵循标识符命名规则，通常使用 `snake_case`。

```python
def greet(name):
    """返回问候语。"""
    return f"Hello, {name}!"
```

函数第一条语句位置的字符串是文档字符串（docstring），可通过 `help(greet)` 或 `greet.__doc__` 查看。

## 调用函数

```python
message = greet("Alice")
print(message)  # Hello, Alice!
```

调用函数前，函数定义所在的代码必须已经执行；函数可以被多次调用。

# 返回值

`return` 将结果返回给调用者，并立即结束当前函数。没有执行 `return` 或只写 `return` 时，返回值都是 `None`。

```python
def add(a, b):
    return a + b


def get_user():
    return "张三", 18


result = add(1, 2)
name, age = get_user()  # 多个返回值实际会打包为元组
```

函数可以有多个出口，但应保证每条执行路径的返回值含义清晰。

# 参数

## 形参与实参

- **形参**：定义函数时声明的参数。
- **实参**：调用函数时传入的对象。

Python 采用“对象引用的共享传递”：函数接收的是对象引用。函数内部修改可变对象会影响调用者；给参数重新赋值只会改变函数内部的绑定。

```python
def update(items):
    items.append(3)  # 修改原列表
    items = [9]      # 只改变局部变量的绑定


values = [1, 2]
update(values)
print(values)  # [1, 2, 3]
```

## 位置参数和关键字参数

位置参数按照定义顺序传入，关键字参数使用 `参数名=值` 传入。位置参数必须写在关键字参数之前。

```python
def greet(name, greeting):
    return f"{greeting}, {name}"


greet("Alice", "Hi")
greet(name="Alice", greeting="Hi")
greet("Alice", greeting="Hi")
```

参数缺失、重复传入或传入未声明的关键字时，会抛出 `TypeError`。

## 默认参数

默认参数在定义函数时确定，调用时可以省略：

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}"


greet("Bob")        # Hello, Bob
greet("Bob", "Hi")  # Hi, Bob
```

非默认参数必须放在默认参数之前。不要直接使用列表、字典等可变对象作为默认值，因为默认值只创建一次，会在多次调用之间共享。

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## 仅限位置参数和仅限关键字参数

参数列表中的 `/` 和 `*` 用于限制调用方式：

- `/` 左侧的参数只能按位置传入。
- `*` 右侧的参数只能按关键字传入。

```python
def connect(host, port, /, *, timeout=5):
    ...


connect("localhost", 5432, timeout=10)
```

这种写法可以固定参数的调用方式，避免参数名成为不必要的接口约束。

## 可变数量参数

- `*args`：收集多余的位置参数，类型为元组。
- `**kwargs`：收集多余的关键字参数，类型为字典。

```python
def describe(*args, **kwargs):
    print(args)
    print(kwargs)


describe(1, 2, name="Alice")
# (1, 2)
# {'name': 'Alice'}
```

`*` 和 `**` 也可以在调用时解包可迭代对象和映射：

```python
values = [1, 2]
options = {"sep": "-"}
print(*values, **options)  # 1-2
```

# 类型注解

类型注解用于表达参数和返回值的预期类型，供阅读、IDE 和静态检查工具使用；Python 默认不会在运行时自动检查类型。

```python
def add(a: int, b: int) -> int:
    return a + b
```

注解会保存在函数的 `__annotations__` 属性中。实际类型设计应结合 `list[str]`、`dict[str, int]`、`int | None` 等现代写法和项目的类型检查工具。

# 变量作用域

Python 查找名称时通常遵循 LEGB 顺序：局部作用域（Local）、外层函数作用域（Enclosing）、全局作用域（Global）和内置作用域（Built-in）。

## 局部变量

函数内赋值的名称默认是局部变量，只能在函数内部访问：

```python
def show_message():
    message = "局部变量"
    print(message)


show_message()
# print(message)  # NameError
```

## 全局变量和 `global`

函数可以读取全局变量，但函数内一旦对某名称赋值，该名称默认就是局部变量。需要在函数内修改全局变量时，使用 `global`：

```python
count = 0


def increment():
    global count
    count += 1
```

实际开发中应优先使用参数和返回值传递状态，减少对全局变量和 `global` 的依赖。

## 外层作用域和 `nonlocal`

嵌套函数可以读取外层函数的局部变量。需要在内层函数中重新绑定外层变量时，使用 `nonlocal`：

```python
def counter():
    value = 0

    def increment():
        nonlocal value
        value += 1
        return value

    return increment


next_value = counter()
print(next_value())  # 1
print(next_value())  # 2
```

内层函数保存外层变量的行为称为闭包。`nonlocal` 不能用于修改全局变量。

# `lambda` 表达式

`lambda` 用于创建只有一个表达式的匿名函数，表达式的结果就是返回值：

```python
square = lambda number: number * number
print(square(3))  # 9
```

它常作为 `sorted()`、`map()` 等函数的 `key` 或回调参数。逻辑较复杂或需要复用时，应使用 `def` 定义具名函数。

# 函数是一等对象

函数可以赋值给变量、作为参数传递，也可以作为返回值：

```python
def apply(func, value):
    return func(value)


print(apply(str.upper, "python"))  # PYTHON
```

这使得函数可以作为回调函数，并支持装饰器、闭包等更高级的编程方式。

# 常用内置函数

Python 内置了许多可以直接调用的函数，例如：

- `len()`：获取对象长度
- `sum()`：求和
- `min()`、`max()`：获取最小值和最大值
- `sorted()`：返回排序后的新列表
- `enumerate()`：遍历时同时获取索引和值
- `zip()`：按位置组合多个可迭代对象
- `any()`、`all()`：判断可迭代对象中是否存在或全部满足真值条件

完整列表参考[内置函数](https://docs.python.org/zh-cn/3/library/functions.html)。

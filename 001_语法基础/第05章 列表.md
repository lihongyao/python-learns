# 认识列表

在 Python 中，列表是一种非常强大且灵活的数据结构，用于存储一系列有序的元素。

语法格式：

```text
变量名 = [元素 1, 元素 2, 元素 3, ...]
```

注意：

1. 列表的所有元素被有序地放置在一对 **中括号** 内，各个元素之间使用 **逗号** `,` 进行分隔。

   ```python
   # 定义列表
   li = [1, 2, 3]

   # 输出列表及其类型
   print(li, type(li))  # [1, 2, 3] <class 'list'>
   ```

2. 列表中的元素可以是不同类型，也可以嵌套列表、元组、字典、集合等对象。

   ```python
   # 定义列表
   li = [False, 3.5, 'Python', [1, 2]]

   # 输出列表及其类型
   print(li, type(li))  # [False, 3.5, 'Python', [1, 2]] <class 'list'>
   ```

3. 列表是可变序列，可以修改、添加和删除元素。

# 基本使用

## 访问列表中的值

与字符串的索引一样，列表索引从 **0** 开始，第二个索引是 **1**，依此类推。

可以通过索引访问元素，也可以使用切片获取子列表。

```python
colors = ["red", "green", "blue", "yellow", "white", "black"]
print(colors[0])
print(colors[1])
print(colors[2])
```

索引也可以从尾部开始，最后一个元素的索引为 **-1**，往前一位为 **-2**，以此类推。

```python
colors = ["red", "green", "blue", "yellow", "white", "black"]
print(colors[-1])
print(colors[-2])
print(colors[-3])
```

使用下标索引来访问列表中的值，也可以使用方括号 **[]** 的形式进行切片：

```python
nums = [10, 20, 30, 40, 50, 60, 70, 80, 90]
print(nums[0:4])
```

以上实例输出结果：

```
[10, 20, 30, 40]
```

使用负数索引值截取：

```python
cities = ["成都", "重庆", "贵阳", "武汉", "桂林"]

# 读取第二位
print("cities[1]: ", cities[1])
# 从第二位开始（包含）截取到倒数第二位（不包含）
print("cities[1:-2]: ", cities[1:-2])
```

以上实例输出结果：

```
cities[1]:  重庆
cities[1:-2]:  ['重庆', '贵阳']
```

## 遍历列表

列表是可迭代对象，可以使用 `for` 循环遍历其中的每个元素。

```python
# 定义列表
li = ['A', 'B', 'C', 'D']

for i in li:
    print(i)


'''
A
B
C
D
'''
```

# 常用函数

以下函数也适用于列表。`max` 和 `min` 要求元素之间可以比较。

- [`len(items)`](https://docs.python.org/zh-cn/3/library/functions.html#len)：返回列表元素个数
- [`max(items)`](https://docs.python.org/zh-cn/3/library/functions.html#max)：返回列表中的最大值
- [`min(items)`](https://docs.python.org/zh-cn/3/library/functions.html#min)：返回列表中的最小值
- [`list(iterable)`](https://docs.python.org/zh-cn/3/library/functions.html#func-list)：使用可迭代对象创建列表

# 常用方法

## 添加元素

- [`list.append(obj)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.append)：在列表末尾添加一个对象
- [`list.extend(iterable)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.extend)：将可迭代对象中的多个元素追加到列表末尾
- [`list.insert(index, obj)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.insert)：将对象插入指定位置

> **注意**：只在末尾添加一个元素时使用 `append`；需要追加多个元素时使用 `extend`。

## 更新元素

通过指定元素的索引（下标）来修改列表中的元素。

语法格式：

```python
items[index] = value
```

参数说明：

- `index`：要修改的元素的索引位置
- `value`：要赋值给指定索引位置的新值，可以是任意数据类型。

## 查找元素

- `in`：检查一个元素是否存在于列表中，如果元素存在，返回 `True`，否则返回 `False`。
- `not in`：检查一个元素是否不存在于列表中，如果元素不存在，返回 `True`，否则返回 `False`。
- [`list.index(obj)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.index)：返回某个值第一次出现的索引，找不到时抛出 `ValueError`
- [`list.count(obj)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.count)：统计某个元素出现的次数

## 删除元素

- `del`：删除列表中的元素
- [`list.remove(obj)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.remove)：移除某个值的第一个匹配项
- [`list.clear()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.clear)：清空列表
- [`list.pop([index=-1])`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.pop)：移除并返回指定位置的元素，默认移除最后一个元素

## 复制列表

- [`list.copy()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.copy)：返回列表的浅拷贝

## 排序

- [`list.sort(key=None, reverse=False)`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.sort)：就地排序原列表
- [`list.reverse()`](https://docs.python.org/zh-cn/3/library/stdtypes.html#list.reverse)：就地反转列表元素

> **注意**：列表的修改类方法通常直接修改原列表并返回 `None`；`pop` 还会返回被移除的元素。`index`、`count` 和 `copy` 不会修改原列表。

# 列表推导式

列表推导式是 Python 中一种简洁创建列表的方法，可以用一行代码完成原本需要多行循环才能实现的功能。

## 基本语法

列表推导式的基本语法如下：

```python
[表达式 for 元素 in 可迭代对象]
```

简单示例：创建 1～10 的数字列表。

```python
# 传统方法
numbers = []
for i in range(1, 11):
    numbers.append(i)

# 列表推导式
numbers = [i for i in range(1, 11)]
```

## 进阶用法

### 元素转换

需求：将列表中的每个元素乘以 5。

```python
nums = [11, 22, 33, 44, 55, 66]

# 传统方法
result = []
for num in nums:
    result.append(num * 5)

# 列表推导式
result = [num * 5 for num in nums]
```

### 条件过滤

可以在列表推导式中加入条件表达式，过滤出满足条件的元素。

```text
[expression for item in iterable if condition]
```

需求：筛选出列表中的偶数。

```python
nums = [11, 22, 33, 44, 55, 66]

# 传统方法
evens = []
for num in nums:
    if num % 2 == 0:
        evens.append(num)

# 列表推导式
evens = [num for num in nums if num % 2 == 0]
```

## 语法总结

| 语法                                 | 说明     | 示例                               |
| :----------------------------------- | :------- | ---------------------------------- |
| `[x for x in iterable]`              | 基本形式 | `[i for i in range(5)]`              |
| `[x * 2 for x in iterable]`          | 元素转换 | `[n * 2 for n in [1, 2, 3]]`         |
| `[x for x in iterable if condition]` | 条件过滤 | `[n for n in range(10) if n % 2 == 0]` |

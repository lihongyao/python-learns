# 概述

Python 中常用的数值类型包括：

- 整数（`int`）：任意精度整数，大小受可用内存限制。
- 浮点数（`float`）：通常使用双精度二进制浮点数表示。
- 布尔值（`bool`）：`True` 和 `False`，是 `int` 的子类。

数值对象不可变。对数字进行运算不会修改原对象，而是生成新的结果对象。

```python
number = 10
number += 1  # 重新绑定 number，不是修改原来的整数对象
```

整数可以使用下划线增强可读性，也支持二进制、八进制和十六进制字面量：

```python
million = 1_000_000
binary = 0b1010
octal = 0o12
hexadecimal = 0xA
```

# 数字类型转换

调用对应的类型函数可以完成常见转换：

| 函数 | 说明 |
| :--- | :--- |
| `int(x)` | 将 `x` 转换为整数；从浮点数转换时向 0 截断 |
| `int(x, base)` | 按指定进制将字符串 `x` 转换为整数 |
| `float(x)` | 将 `x` 转换为浮点数 |
| `bool(x)` | 将 `x` 转换为布尔值 |

```python
print(int(3.9))             # 3
print(int(-3.9))            # -3
print(int("101", 2))        # 5
print(float("3.14"))        # 3.14
print(bool(0), bool(1))     # False True
```

`int("12.5")` 不能直接转换，因为它不是整数格式；转换失败时通常会抛出 `ValueError`，类型不支持时可能抛出 `TypeError`。

# 常用内置数值函数

以下函数不需要导入模块：

| 函数 | 说明 |
| :--- | :--- |
| `abs(x)` | 返回绝对值 |
| `divmod(a, b)` | 同时返回整除商和余数，结果为 `(a // b, a % b)` |
| `max(...)` | 返回参数或可迭代对象中的最大值 |
| `min(...)` | 返回参数或可迭代对象中的最小值 |
| `pow(x, y)` | 返回 `x ** y` |
| `pow(x, y, mod)` | 返回 `(x ** y) % mod`，适合整数模幂运算 |
| `round(number, ndigits)` | 按指定精度舍入，`ndigits` 可省略 |
| `sum(iterable, start=0)` | 对可迭代对象求和 |

```python
print(abs(-10))             # 10
print(divmod(17, 5))        # (3, 2)
print(max([3, 1, 5]))       # 5
print(min(3, 1, 5))         # 1
print(pow(2, 10, 1000))     # 24
print(round(3.14159, 2))    # 3.14
print(sum([1, 2, 3], 10))   # 16
```

`round()` 采用“银行家舍入”（向偶数舍入）：

```python
print(round(2.5))   # 2
print(round(3.5))   # 4
```

# 浮点数注意事项

浮点数采用二进制近似表示，不能精确表示很多十进制小数：

```python
print(0.1 + 0.2 == 0.3)  # False
```

需要比较浮点数时，优先使用 `math.isclose()`；金额等需要十进制精确计算的场景使用 `decimal.Decimal`。

# `math` 模块

`math` 提供常用的实数数学函数和常量，使用前需要导入：

```python
import math
```

以下函数不处理复数；复数计算使用 `cmath` 模块。

## 常用数学函数

| 函数 | 返回值（描述） |
| :--- | :--- |
| `math.ceil(x)` | 向上取整，返回大于或等于 `x` 的最小整数 |
| `math.floor(x)` | 向下取整，返回小于或等于 `x` 的最大整数 |
| `math.trunc(x)` | 向 0 截断小数部分 |
| `math.exp(x)` | 返回 `e ** x` |
| `math.log(x, base)` | 返回对数，`base` 省略时以 `e` 为底 |
| `math.log10(x)` | 返回以 10 为底的对数 |
| `math.sqrt(x)` | 返回平方根 |
| `math.isclose(a, b, *, rel_tol=1e-09, abs_tol=0.0)` | 判断两个数是否足够接近 |
| `math.isfinite(x)` | 判断是否既不是无穷大也不是 NaN |
| `math.isinf(x)` | 判断是否为正无穷或负无穷 |
| `math.isnan(x)` | 判断是否为 NaN |
| `math.gcd(*integers)` | 返回整数的最大公约数 |
| `math.lcm(*integers)` | 返回整数的最小公倍数 |
| `math.fsum(iterable)` | 更精确地计算浮点数总和 |
| `math.prod(iterable, start=1)` | 计算可迭代对象中元素的乘积 |
| `math.hypot(*coordinates)` | 返回坐标的欧几里得范数 |

```python
import math

print(math.ceil(4.1))                # 5
print(math.floor(4.9))               # 4
print(math.trunc(-4.9))              # -4
print(math.isclose(0.1 + 0.2, 0.3))  # True
print(math.gcd(12, 18))              # 6
print(math.lcm(4, 6))                # 12
print(math.fsum([0.1] * 10))         # 1.0
print(math.prod([2, 3, 4]))          # 24
```

`math.isclose()` 的常用参数：

- `rel_tol`：相对容差，默认值为 `1e-09`。
- `abs_tol`：绝对容差，比较接近 0 的数时通常需要显式设置。

```python
print(math.isclose(0.000001, 0, abs_tol=0.00001))  # True
```

## 对数与指数

```python
print(math.exp(1))          # e
print(math.log(math.e))     # 1.0
print(math.log(8, 2))       # 3.0
print(math.log10(100))      # 2.0
print(math.sqrt(16))        # 4.0
```

# 随机数函数

`random` 模块生成伪随机数，常用于游戏、模拟、测试数据和抽样。使用前需要导入：

```python
import random
```

伪随机数不适合生成密码、验证码或令牌等安全凭据；安全场景应使用 `secrets` 模块。

| 函数 | 描述 |
| :--- | :--- |
| `random.random()` | 生成 `[0, 1)` 范围内的浮点数 |
| `random.randrange(stop)`  <br />`random.randrange(start, stop[, step])` | 从对应 `range()` 中随机返回一个整数，`stop` 不包含 |
| `random.randint(a, b)` | 返回 `[a, b]` 范围内的随机整数，包含两端 |
| `random.uniform(a, b)` | 返回 `a` 和 `b` 之间的随机浮点数 |
| `random.choice(seq)` | 从非空序列中随机选择一个元素 |
| `random.choices(population, weights=None, k=1)` | 有放回地随机选择 `k` 个元素，返回列表 |
| `random.sample(population, k)` | 无放回地随机抽取 `k` 个元素，返回列表 |
| `random.shuffle(x)` | 原地打乱可变序列，返回 `None` |
| `random.seed(a)` | 设置随机数种子，用于复现伪随机序列 |

```python
import random

random.seed(42)
print(random.randint(1, 10))
print(random.choice(["红", "黄", "蓝"]))
print(random.sample(range(10), k=3))

items = [1, 2, 3, 4]
random.shuffle(items)
print(items)
```

`random.choices()` 允许重复选择；`random.sample()` 不允许同一位置被重复抽取：

```python
print(random.choices(["A", "B", "C"], k=5))
print(random.sample(["A", "B", "C"], k=2))
```

`random.shuffle()` 会直接修改原列表，不要写成通过返回值接收结果：

```python
items = [1, 2, 3]
result = random.shuffle(items)

print(result)  # None
print(items)   # 已被原地打乱
```

# 三角函数

`math` 模块中的三角函数使用弧度作为参数和返回值单位。

| 函数 | 描述 |
| :--- | :--- |
| `math.sin(x)` | 返回 `x`（弧度）的正弦值 |
| `math.cos(x)` | 返回 `x`（弧度）的余弦值 |
| `math.tan(x)` | 返回 `x`（弧度）的正切值 |
| `math.asin(x)` | 返回反正弦值（弧度） |
| `math.acos(x)` | 返回反余弦值（弧度） |
| `math.atan(x)` | 返回反正切值（弧度） |
| `math.atan2(y, x)` | 根据坐标 `(x, y)` 返回反正切值（弧度） |
| `math.hypot(x, y)` | 返回 `sqrt(x * x + y * y)` |
| `math.degrees(x)` | 将弧度转换为角度 |
| `math.radians(x)` | 将角度转换为弧度 |

```python
print(math.sin(math.pi / 2))       # 1.0
print(math.degrees(math.pi / 2))    # 90.0
print(math.radians(180))            # 3.141592653589793
```

# `decimal`：精确的十进制计算

`float` 适合一般科学和工程计算；金额、税费等需要十进制精确结果的场景，使用 `Decimal`：

```python
from decimal import Decimal

print(0.1 + 0.2)  # 0.30000000000000004
print(Decimal("0.1") + Decimal("0.2"))  # 0.3
```

创建 `Decimal` 时优先传入字符串，不要直接传入浮点数：

```python
from decimal import Decimal

print(Decimal("3.14"))  # Decimal('3.14')
print(Decimal(3.14))    # 包含浮点数本身的二进制误差
```

常用操作：

| API | 说明 |
| :--- | :--- |
| `Decimal(value)` | 创建十进制数，金额通常传入字符串 |
| `Decimal.quantize(exp)` | 按指定小数位数舍入 |
| `getcontext().prec` | 设置当前十进制上下文的计算精度 |

```python
from decimal import Decimal

amount = Decimal("10.235")
print(amount.quantize(Decimal("0.01")))  # 10.24
```

# `statistics`：基础统计

`statistics` 提供常用的描述性统计函数，不需要安装第三方库：

| 函数 | 描述 |
| :--- | :--- |
| `statistics.mean(data)` | 算术平均数 |
| `statistics.fmean(data)` | 转为浮点数后计算平均数，返回 `float` |
| `statistics.median(data)` | 中位数 |
| `statistics.mode(data)` | 众数 |
| `statistics.multimode(data)` | 返回所有众数 |
| `statistics.stdev(data)` | 样本标准差 |
| `statistics.pstdev(data)` | 总体标准差 |
| `statistics.variance(data)` | 样本方差 |
| `statistics.pvariance(data)` | 总体方差 |

```python
from statistics import mean, median, mode, stdev

scores = [80, 85, 85, 90, 95]

print(mean(scores))    # 87.0
print(median(scores))  # 85
print(mode(scores))    # 85
print(stdev(scores))   # 样本标准差
```

`stdev()` 和 `variance()` 针对样本；`pstdev()` 和 `pvariance()` 针对总体。数据为空或数据点不足时，相关函数可能抛出 `StatisticsError`。

# 概述

Python 的数字类型用于存储数值。数字对象不可变；如果重新给变量赋值，变量会指向新的数字对象。

以下示例会创建两个数字对象：

```python
num1 = 1
num2 = 2
```

可以使用 `del` 语句删除变量名与对象之间的引用。

语法示例：

```python
del var1
del var1, var2, var3
```

例如：

```python
var = 1
var_a, var_b = 2, 3
del var
del var_a, var_b
```

Python 支持三种不同的数值类型：

- 整型（`int`）：正整数、负整数或 0。Python 3 的整数没有固定大小限制（受可用内存限制），`bool` 是 `int` 的子类型。
- 浮点型（`float`）：带有小数部分的数值，也可以使用科学计数法表示，例如 `2.5e2` 等于 `250.0`。
- 复数（`complex`）：由实部和虚部组成，可以用 `a + bj` 或 `complex(a, b)` 表示。

# 数字类型转换

有时候需要在不同数字类型之间进行转换，可以直接调用对应的类型函数。

- `int(x)`：将 `x` 转换为整数；从浮点数转换时会直接截去小数部分。
- `float(x)`：将 `x` 转换为浮点数。
- `complex(x)`：将 `x` 转换为复数，虚部为 0。
- `complex(x, y)`：使用 `x` 和 `y` 分别作为实部和虚部创建复数。

> **注意**：字符串必须是合法的数字文本，例如 `int('12')` 可以转换，而 `int('12.5')` 会报错。

# 数学函数

`abs`、`max`、`min`、`pow`、`round` 是内置函数；`ceil`、`exp`、`fabs` 等函数位于 `math` 模块，使用前需要 `import math`。

| 函数                  | 返回值（描述）                                                |
| :-------------------- | :------------------------------------------------------------ |
| `abs(x)`              | 返回数字的绝对值，如 `abs(-10)` 返回 `10`。                   |
| `math.ceil(x)`        | 向上取整，如 `math.ceil(4.1)` 返回 `5`。                      |
| `math.exp(x)`         | 返回 `e` 的 `x` 次方，如 `math.exp(1)`。                      |
| `math.fabs(x)`        | 以浮点数形式返回绝对值，如 `math.fabs(-10)` 返回 `10.0`。    |
| `math.floor(x)`       | 向下取整，如 `math.floor(4.9)` 返回 `4`。                    |
| `math.log(x, base)`   | 返回对数，`base` 可省略，如 `math.log(math.e)` 返回 `1.0`。 |
| `math.log10(x)`       | 返回以 10 为底的对数，如 `math.log10(100)` 返回 `2.0`。      |
| `max(x1, x2, ...)`    | 返回给定参数或可迭代对象中的最大值。                          |
| `min(x1, x2, ...)`    | 返回给定参数或可迭代对象中的最小值。                          |
| `math.modf(x)`        | 返回 `(小数部分, 整数部分)`，两部分均为浮点数且符号与 `x` 相同。 |
| `pow(x, y)`           | 返回 `x ** y` 的结果。                                        |
| `round(x, n)`         | 按指定的小数位数进行舍入，`n` 可省略，省略时返回整数。       |
| `math.sqrt(x)`        | 返回 `x` 的平方根。                                           |

> **注意**：`round` 在恰好位于两个数中间时通常取偶数一侧，例如 `round(2.5)` 的结果是 `2`。

# 随机数函数

随机数常用于游戏、模拟和抽样等场景。`random` 模块生成的随机数不适合用于密码或其他安全场景。

使用这些函数前，需要先执行 `import random`。

| 函数                                  | 描述                                                         |
| :------------------------------------ | :----------------------------------------------------------- |
| `random.choice(seq)`                  | 从序列中随机挑选一个元素，例如 `random.choice(range(10))`。   |
| `random.randrange(start, stop, step)` | 从 `range(start, stop, step)` 中随机返回一个整数，`stop` 不包含在内。 |
| `random.random()`                      | 随机生成一个 `[0, 1)` 范围内的浮点数。                       |
| `random.seed(x)`                       | 设置随机数生成器的种子；省略时由 Python 自动选择。           |
| `random.shuffle(lst)`                  | 原地随机打乱序列中的元素，返回值为 `None`。                  |
| `random.uniform(x, y)`                 | 随机生成一个 `x` 到 `y` 之间的浮点数。                       |

# 三角函数

`math` 模块提供以下三角函数，参数和返回值默认使用弧度：

| 函数                | 描述                                                         |
| :------------------ | :----------------------------------------------------------- |
| `math.acos(x)`      | 返回 `x` 的反余弦值（弧度）。                                |
| `math.asin(x)`      | 返回 `x` 的反正弦值（弧度）。                                |
| `math.atan(x)`      | 返回 `x` 的反正切值（弧度）。                                |
| `math.atan2(y, x)`  | 根据 `x`、`y` 坐标返回反正切值（弧度）。                     |
| `math.cos(x)`       | 返回 `x`（弧度）的余弦值。                                  |
| `math.hypot(x, y)`  | 返回欧几里得范数，即 `sqrt(x * x + y * y)`。                |
| `math.sin(x)`       | 返回 `x`（弧度）的正弦值。                                  |
| `math.tan(x)`       | 返回 `x`（弧度）的正切值。                                  |
| `math.degrees(x)`   | 将弧度转换为角度，例如 `math.degrees(math.pi / 2)` 返回 `90.0`。 |
| `math.radians(x)`   | 将角度转换为弧度。                                           |

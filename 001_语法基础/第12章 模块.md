# 模块

## 定义

在 Python 中，一个 `.py` 文件通常就是一个模块。模块中可以定义函数、类、变量和可执行代码。

## 模块分类

1. **标准库模块**：Python 自带的模块，例如 `copy`、`random`、`time` 和 `os`，无需额外安装即可导入。
2. **第三方模块**：由社区或其他开发者提供，需要先安装后使用。
3. **自定义模块**：在项目中自己创建的 `.py` 文件。

### 第三方模块

Python 使用 `pip` 管理第三方包，通常在命令行中执行：

```shell
python -m pip install requests
```

### 自定义模块

自定义模块的命名应遵循 Python 标识符规则，并尽量避免与标准库模块或已安装的第三方模块重名，否则可能导入到错误的模块。

# 导入模块

将代码拆分到不同模块后，可以通过导入来复用其中的函数、类和变量。导入语句通常放在文件开头，并且同一模块在一次运行中通常只会初始化一次。

## `import 模块名 [as 别名]`

`import` 导入模块对象，使用其中的内容时需要加上模块名或别名作为前缀。

新建 `test.py` 文件，内容如下：

```python
import random

__all__ = ["version", "add", "get_random_num"]
version = "v1.0.0"


def add(a: int, b: int):
    return a + b


def get_random_num():
    return random.randint(1, 100)
```

导入并使用模块中的功能：

```python
import test

print(test.version)
print(test.add(1, 2))
print(test.get_random_num())
```

如果模块名较长，可以使用 `as` 设置别名：

```python
import test as t

print(t.version)
print(t.add(1, 2))
```

## `from 模块名 import 功能名`

只导入模块中的指定功能，使用时不需要添加模块名前缀：

```python
from test import add

print(add(1, 2))
```

也可以同时导入多个功能：

```python
from test import add, version

print(version)
print(add(1, 2))
```

## `from 模块名 import *`

使用 `*` 会导入模块中公开的名称。如果模块定义了 `__all__`，则只导入其中列出的名称；没有定义时，通常导入不以下划线开头的名称。

```python
from test import *

print(version)
print(add(1, 2))
print(get_random_num())
```

> **注意**：不建议在大型项目中使用 `from ... import *`，因为它会降低代码可读性，并可能造成同名变量或函数相互覆盖。优先使用 `import 模块名` 或显式导入指定功能。

# 以主程序的形式执行

每个模块都有一个特殊变量 `__name__`：

- 直接运行模块时，`__name__` 的值是 `"__main__"`。
- 被其他模块导入时，`__name__` 的值是模块名。

可以使用 `if __name__ == "__main__":` 区分直接运行和被导入两种情况：

```python
import random

version = "v1.0.0"


def get_random_num():
    return random.randint(1, 100)


if __name__ == "__main__":
    print(__name__)
    print(f"当前版本：{version}")
    print(get_random_num())
```

这样，模块被导入时只会定义函数和变量，不会执行主程序代码。

# 包

包（Package）是用于组织多个相关模块的目录结构，可以帮助划分功能和管理项目代码。一个常见的包结构如下：

```text
python-project/
├── main.py
└── utils/
    ├── __init__.py
    ├── a.py
    └── b.py
```

`__init__.py` 通常用于标识和初始化包。导入包时，其中的顶层代码会执行，因此应保持初始化逻辑简洁。

## 创建包

`utils/__init__.py`：

```python
from . import a
from . import b
```

`utils/a.py`：

```python
name = "模块 a"
```

`utils/b.py`：

```python
name = "模块 b"
```

## 使用包

导入包：

```python
import utils

print(utils.a.name)
```

也可以从包中导入指定模块：

```python
from utils import a

print(a.name)
```

## `__all__` 变量

`__all__` 是一个字符串列表，用于控制 `from 模块 import *` 导入的名称：

```python
__all__ = ["version", "add"]
```

在包的 `__init__.py` 中，`__all__` 也可以列出允许通过 `from 包 import *` 导入的子模块名称。没有定义 `__all__` 时，不会自动导入包中的所有子模块。
